# Consulting Output Generation Skill (Goodbye Consulting!)

**Official Name**: `all-consulting-skills`

Enterprise-grade consulting deliverable generator producing strategy, management, and technology consulting quality outputs

## 📋 Overview

This skill is a comprehensive guide for generating high-quality research reports and proposal documents based on top-tier consulting firm methodologies.

It covers the entire consulting project flow, from issue structuring to hypothesis testing, framework analysis, and final document creation.

> 📝 **About Output Format**: This skill generates slide manuscripts in Markdown format. The created MD files can be converted into actual presentation slides using AI slide generation tools such as [Gamma AI](https://gamma.app/), [Beautiful.ai](https://www.beautiful.ai/), and [Slides AI](https://www.slidesai.io/).

### ✨ Key Features

- ✅ **Web Search Integration** - Analysis based on real data (8-15 information collections)
- ✅ **Practical Frameworks** - 15+ strategic frameworks
- ✅ **Wide Coverage** - 23 cases from business strategy to technology and ESG
- ✅ **Multi-Format Support** - 8 consulting firm styles
- ✅ **Progress Visualization** - Real-time status display (⬜📝✅)
- ✅ **Incremental Approach** - Guaranteed completion through 4 phases

## 🚀 Quick Start

### 1. Installation

**Option A: Using Skills CLI** (Recommended)
```bash
npx skills add <your-github-username>/awesome-claude-skills
```

**Option B: Manual Installation**
```bash
# Clone the repository
git clone https://github.com/<your-github-username>/awesome-claude-skills.git

# Copy to your project
cp -r awesome-claude-skills/consulting-skills/all-consulting .claude/skills/
```

**Option C: Direct Upload**
- Download the [all-consulting](.) folder
- Upload to your Claude conversation

### 2. Usage

**In Claude Code (VS Code)**:
```
You: "I want to develop a market entry strategy"
Claude: 🎯 Activating all-consulting-skills...
```

**In Claude.ai**:
- Upload the SKILL.md file
- Start asking Claude to create consulting deliverables

## 📖 How It Works

### Four-Phase Approach

#### Phase 0: Format Selection (2-3 min)
- Choose preferred consulting firm format
- System adapts to selected style

#### Phase 1: Problem Definition (20-30 min)
- Issue clarification and structuring (MECE)
- Hypothesis formation
- Framework selection
- Initial data collection (8-15 sources)

#### Phase 2: Document Design (15-20 min)
- Storyline development
- Slide structure definition
- Progress tracking setup (⬜📝✅)
- Data requirements specification

#### Phase 3: Slide Creation (40-80 min)
- One slide at a time approach
- Real-time progress updates
- User confirmation at each step
- Format-specific styling application

#### Phase 4: Quality Assurance (10-15 min)
- Consistency check
- Quality standard verification
- Final adjustments

**Total Time**: ~90-120 minutes (vs. 40 hours traditional approach)

## 🆘 Troubleshooting

### Common Issues

**Issue**: Format not applying correctly
- **Solution**: Clearly specify format in initial request
- Restart with explicit format selection

**Issue**: Too much/too little detail
- **Solution**: Provide feedback during creation
- Ask Claude to adjust depth level

**Issue**: Work interrupted unexpectedly
- **Solution**: Upload workflow file to resume
- All progress is saved automatically

**Issue**: Need to change format mid-way
- **Solution**: Complete current version first
- Request regeneration in new format
