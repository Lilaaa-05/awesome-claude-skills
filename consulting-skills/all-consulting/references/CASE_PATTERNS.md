# Case Pattern Library

Complete reference for 23+ consulting case types with frameworks, approaches, and deliverable structures.

## Business Strategy Cases (12)

### 1. New Market Entry

**Key Question**: Should we enter this market?

**Frameworks**:
- 3C Analysis (Customer, Competitor, Company)
- Porter's 5 Forces
- PEST Analysis
- STP (Segmentation, Targeting, Positioning)

**Typical Structure**:
1. Market Attractiveness
   - Market size and growth
   - Customer needs and segments
   - Profitability potential
2. Competitive Landscape
   - Key competitors
   - Competitive intensity
   - Entry barriers
3. Our Fit
   - Capabilities match
   - Competitive advantages
   - Resource requirements
4. Entry Strategy
   - Entry mode (organic, acquisition, partnership)
   - Positioning
   - Go-to-market plan
5. Financial Case
   - Investment required
   - Revenue projections
   - ROI and payback

## Common Slide Structures

### Executive Summary Slide
```
- Key Findings (Top 3-5)
- Main Recommendations
- Expected Impact
- Critical Actions
```

### Situation Analysis Slide
```
- Current State
- Key Issues
- Root Causes
- Implications
```

### Options Analysis Slide
```
- Option 1: [Description]
  - Pros / Cons
  - Impact / Feasibility
- Option 2: [Description]
  - Pros / Cons
  - Impact / Feasibility
- Recommended Option
```

### Roadmap Slide
```
- Phase 1 (0-6 months): Quick wins
- Phase 2 (6-12 months): Foundation
- Phase 3 (12-24 months): Scale
- Milestones & Dependencies
```

### Financial Impact Slide
```
- Investment Required
- Revenue Impact
- Cost Impact
- NPV / IRR / Payback
```

## Tips by Case Type

### Strategy Cases
- Focus on "So What?"
- Quantify everything possible
- Be action-oriented
- Consider implementation

### Technology Cases
- Balance technical and business
- Address change management
- Provide realistic timelines
- Include risk mitigation

### ESG/Sustainability Cases
- Link to business value
- Set measurable targets
- Address stakeholder expectations
- Plan for reporting
