Detailed explanation of slide formats (layout, color schemes, typography, visual elements) for each consulting firm.

This guide provides specific **slide design composition** for each firm:
- **Layout**: Grid structure, element placement methods
- **Color Scheme**: Main colors, accent colors, background colors
- **Typography**: Font types, sizes, usage
- **Visuals**: Chart and diagram types and expression methods
- **Emphasis**: How to highlight important information

## Available Formats

### 1. McKinsey & Company

**Slide Design Composition**:
- **Layout**: 3-tier structure - title at top, main message in center, data/charts at bottom
- **Color Scheme**: Blue (#003DA5) as main, white background, gray (#666666) for supplements
- **Typography**: Arial or Helvetica, headings 20pt, body 12-14pt
- **Visuals**: Simple bar graphs, line charts, MECE tree diagrams, matrices
- **Emphasis**: Important numbers in blue boxes, arrows showing causality

**Key Characteristics**:
- Data-driven approach
- Pyramid structure (conclusion first)
- "So What?" clearly stated
- Minimal visual elements
- Emphasis on logical clarity

**Typical Slide Structure**:
```
┌─────────────────────────────────────┐
│ [Slide Title]                    #1 │
├─────────────────────────────────────┤
│ Key Message: [One clear sentence]   │
├─────────────────────────────────────┤
│                                     │
│        [Simple Chart/Graph]         │
│                                     │
├─────────────────────────────────────┤
│ • Supporting Point 1                │
│ • Supporting Point 2                │
│ • Supporting Point 3                │
├─────────────────────────────────────┤
│ Source: [Data source]        McKinsey│
└─────────────────────────────────────┘
```

## Slide Design Application Points

### Ensuring Consistency
- **Color Scheme**: Unify specified colors of selected firm across all slides
- **Typography**: Unify font, size, line spacing
- **Layout Grid**: Use same grid system
- **Visual Style**: Unify chart and diagram design

### Basic Layout Composition

Each slide consists of the following elements:

1. **Header Section** (Top 15-20%)
   - Slide title
   - Section name (optional)
   - Page number

2. **Main Content Section** (Center 60-70%)
   - Key message
   - Data visualization
   - Charts and diagrams
   - Bullet points and explanatory text

3. **Footer Section** (Bottom 5-10%)
   - Sources and annotations
   - Date and confidentiality notice
   - Firm logo (if applicable)

### Customization Allowance
- Reference firm characteristics while optimizing for project
- Adjust according to audience and purpose
- Selectively utilize good points from multiple formats

### Quality Standards
Mandatory for any format:
- **1 Slide = 1 Message**: One clear claim per slide
- **Cite Data Sources**: Include citations for all data
- **Logical Structure**: Clear "So What?" and "Why So?"
- **Actionable Recommendations**: Present specific actions
- **Appropriate White Space**: Avoid information overload (30-40% of slide area should be white space)
