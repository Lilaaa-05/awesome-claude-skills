# コンサルティングアウトプット生成スキル(さよならコンサル！)

**正式名称**: `jp-consulting-skills`

戦略・総合・テクノロジーコンサルティングファーム品質のアウトプット生成スキル

## 📋 概要

このスキルは、トップティアコンサルティングファームのメソドロジーに基づいた高品質な調査報告書・提案資料を生成するための包括的なガイドです。

課題構造化から仮説検証、フレームワーク分析、最終資料作成まで、コンサルティングプロジェクトの全フローをカバーしています。

> 📝 **出力形式について**: このスキルはMarkdown形式でスライド原稿を生成します。作成したMDファイルは、[Gamma AI](https://gamma.app/)、[Beautiful.ai](https://www.beautiful.ai/)、[Slides AI](https://www.slidesai.io/)などのスライド生成AIツールで、実際のプレゼンテーションスライドに変換できます。

### ✨ 主な特徴

- ✅ **Web検索統合** - 実データに基づく分析（8-15件の情報収集）
- ✅ **実践的フレームワーク** - 15種類以上の戦略フレームワーク
- ✅ **幅広い対応領域** - ビジネス戦略からテクノロジー、ESGまで23ケース
- ✅ **マルチフォーマット対応** - 10社のコンサルファームスタイル
- ✅ **進捗可視化** - リアルタイムステータス表示（⬜📝✅）
- ✅ **段階的アプローチ** - 4つのフェーズで確実に完成

### ⚡ コンサル業務効率化効果

このスキルを使用することで、通常**1週間（40時間）**かかるコンサルティング資料作成作業を**75-120分**に短縮できます。

| 従来の作業時間 | スキル使用時 | 効率化率 |
|---------------|-------------|---------|
| 1週間（40時間） | 75-120分 | **約95-97%削減** |

> 💡 **実務への影響**: コンサルタントは戦略立案や顧客コミュニケーションなど、より高付加価値な業務に時間を集中できます。

## 📈 作業の流れ（4フェーズ）

### Phase 0: 企業フォーマット選択
⏱️ **所要時間**: 2-3分

選択したフォーマットの特性を理解し、適用準備

### Phase 1: 問題設定（課題構造化）
⏱️ **所要時間**: 20-30分

- イシューの特定
- MECEによる分解
- 仮説の立案
- Web検索で初期データ収集（8-15件）

### Phase 2: 資料構成の設計
⏱️ **所要時間**: 15-20分

- ストーリーラインの構築
- 作成流れファイルの作成
- 各スライドのデータ要件定義
- 進捗ステータスの初期化（全て⬜未作成）

### Phase 3: スライド作成
⏱️ **所要時間**: 40-80分

1枚ずつ丁寧にMarkdown形式でスライド原稿を作成
- タイトルとメッセージ
- データとビジュアル
- So What（示唆）
- 出所の明記

**📄 出力ファイル**: `[プロジェクト名]_演示稿_[日付].md`

**🎨 実際のスライド化**: 完成したMDファイルを以下のツールで変換
- [Gamma AI](https://gamma.app/) - AI駆動の自動デザイン
- [Beautiful.ai](https://www.beautiful.ai/) - テンプレートベース
- [Slides AI](https://www.slidesai.io/) - Google Slides連携
- [Pitch](https://pitch.com/) - チームコラボレーション

**進捗表示例:**
```
⬜⬜⬜⬜⬜⬜⬜⬜ → ✅📝⬜⬜⬜⬜⬜⬜ → ✅✅✅✅✅✅✅✅
```

**記号の意味:**
- ⬜ 未作成
- 📝 作成中
- ✅ 完成

### Phase 4: 品質確認
⏱️ **所要時間**: 10-15分

- 全体の整合性チェック
- ストーリーラインの確認
- フォーマット要件の検証

### プレゼンテーション時のポイント

#### 導入 (15秒)
「市場環境について分析した結果をご説明します。」

**ポイント**: まずグラフ全体を見せて、全体像を把握してもらう

#### メインメッセージ (30秒)
「このグラフが示すように、国内EC市場は年率15%で急成長しており、2030年には30兆円に達する見込みです。」

**ポイント**: グラフの右上がりの部分を指しながら説明

#### キーポイント展開 (45秒)
「特に注目すべき点が3つあります。」
- 「1点目、モバイルECの比率が既に70%を超えています」
- 「2点目、Z世代が市場拡大の主要ドライバーです」
- 「3点目、地方都市での成長が都市部を上回っています」

**ポイント**: 各ポイントを順番に強調、数字は明確に発声、聴衆の反応を見ながらペース調整

#### 結論 (15秒)
「これらのデータから、今が市場参入の絶好機であると言えます。」

**ポイント**: 強い口調で断言、次のスライドへの橋渡し

#### 質疑応答への備え

**想定される質問**:
- Q: 「なぜ15%成長と言えるのか？」

- Q: 「地方都市での成長要因は？」

3. 調査会社レポート（矢野経済研究所、富士経済など）
4. 主要メディア（日経、東洋経済など）
5. 企業IR資料

**データ収集の特徴**:
- フェーズ1で8-15件の初期情報収集
- 各スライドで3-8件の追加検索
- 出所URLを必ず記録
- 複数ソースでクロスチェック

## 💼 使用例

### 例1: 新規市場参入の検討

```
ユーザー: 「東南アジア市場への参入を検討したい」

スキルの対応:
1. イシュー特定
   → 「どの国に、どの方法で参入すべきか？」

2. ケースパターン「新規市場参入」を参照

3. 5C、Porter 5 Forces を適用

4. Web検索で8-15件の市場データを収集

5. スライド構成設計（進捗ステータス付き）

6. Markdown形式でスライドを順次生成
   ⬜⬜⬜⬜⬜ → ✅📝⬜⬜⬜ → ✅✅✅✅✅

7. （オプション）PowerPointに変換
```

### 例2: 売上減少対策

```
ユーザー: 「売上が10%減少している。原因と対策を知りたい」

スキルの対応:
1. イシュー特定
   → 「売上減少の主要因は何で、どの対策が有効か？」

2. イシューツリーで分解
   売上減少 = 顧客数減少 + 客単価低下

3. 仮説立案
   仮説: 「競合の低価格攻勢が主因」

4. データ収集・分析で検証

5. ケースパターン「売上増加」「競合対策」を参照

6. 資料作成
```
