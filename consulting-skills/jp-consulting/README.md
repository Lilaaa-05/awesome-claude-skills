# jp-consulting-output スキル

コンサルティング向け包括的アウトプット生成スキル(Web検索機能統合版)

## 概要

このスキルは、戦略・総合・テクノロジーコンサルティングにおける高品質なアウトプット(調査報告書、提案資料)を生成するための包括的なガイドです。

課題構造化から仮説検証、フレームワーク分析、最終資料作成まで、コンサルティングプロジェクトの全フローをカバーしています。

**v1.0のリリース内容**:
- ✅ Web検索機能を統合
- ✅ 実践的なフレームワークガイド
- ✅ ビジネス・テクノロジー両分野に対応
- ✅ 複数企業フォーマット対応(McKinsey/BCG/Bain/Deloitte/EY/PwC/Accenture/Abeam/NRI/標準)
- ✅ 進捗可視化システム(⚫📝✅)
- ✅ より豊富な分析コンテンツ(8-15件の情報収集)

## 対応内容

- **資料タイプ**: 調査報告書、提案資料
- **出力形式**: Markdown
- **言語**: 日本語のみ
- **データ収集**: Web検索（自動）、フェルミ推定（必要時）

## 使用方法

### 1. 初めて使用する場合

#### ステップ1: スキルを呼び出す

以下のようにスキルを呼び出します：

```
「jp-consulting-outputで○○市場の参入可否を分析してください」
「jp-consulting-outputでクラウド移行戦略を作成したい」
```

#### ステップ2: 課題とフォーマットを選択

スキルが自動的に以下の質問をします：

```
どのような課題について資料を作成しますか?

また、ご希望の資料フォーマットはありますか?
(McKinsey/BCG/Bain/Deloitte/EY/PwC/Accenture/Abeam/NRI/標準/指定なし)
```

**回答例**:
- 課題: 「東南アジア市場への参入検討」「DX推進戦略の立案」
- フォーマット: 「McKinsey」「BCG」など（会社名のみで指定可）

**利用可能なフォーマット**:
- McKinsey
- BCG
- Bain
- Deloitte
- EY
- PwC
- Accenture
- Abeam (アビームコンサルティング)
- NRI (野村総合研究所)
- 標準 (汎用フォーマット)

> 📖 各フォーマットの詳細は [FIRM_FORMATS.md](references/FIRM_FORMATS.md) を参照

#### ステップ3: 自動で作業開始

必要に応じて追加情報を確認しながら、スキルが段階的に作業を進めます。
途中で分からないことがあれば、スキルが質問しますので答えてください。

---

### 2. プロジェクトの進行（4つのフェーズ）

スキルは以下の4つのフェーズでプロジェクトを進めます：

#### **フェーズ0: 企業フォーマット選択** (所要時間: 2-3分)
選択したフォーマットの特性を理解し、適用準備をします。

#### **フェーズ1: 課題構造化** (所要時間: 20-30分)
**何をするか**: 問題を整理し、答えるべき問いを明確にします。

**実施内容**:
- イシュー（論点）の特定
  - 例: 「東南アジア市場に参入すべきか？」
- イシューツリーの構築（MECE原則で論点を分解）
- 目的・ゴールの明確化
- ステークホルダー分析
- マクロ環境分析(PEST)

**成果物**: イシュー分析文書

#### **フェーズ2: 分析と作成流れ設計** (所要時間: 15-20分)
**何をするか**: データを集めて分析し、資料の構成を設計します。

**実施内容**:
- 仮説の立案（仮説思考）
- 最適なフレームワークの選定
- **Web検索で自動データ収集**(8-15件)
  - 市場規模、成長率、市場動向
  - 競合情報、市場シェア
  - 業界トレンド、ベンチマーク
  - 顧客ニーズ、消費者動向
- フェルミ推定（必要時）
- ストーリーラインの構築
- スライド構成設計（進捗ステータス初期化）

**成果物**: 
- 仮説検証文書
- `[プロジェクト名]_作成流れ_[日付].md`（全スライドの設計仕様）

#### **フェーズ3: スライド作成** (所要時間: 40-80分)
**何をするか**: 1枚ずつスライドを丁寧に作成します。

**作成フロー**（各スライド共通）:
1. **進捗表示** - 現在の進捗を表示
   ```
   完成: 2/15枚 (13%)
   ✅ 1. 表紙
   ✅ 2. 全体サマリー
   📝 3. 市場環境分析 ← 作成中
   ⬜ 4. 競合分析
   ...
   ```

2. **スライドイメージ図の提示** - 視覚的な構成を先に確認
   ```
   ┌─────────────────────────────┐
   │ タイトル: 市場規模の推移    │
   ├─────────────────────────────┤
   │ メッセージ: 市場は年10%成長 │
   ├─────────────────────────────┤
   │        [折れ線グラフ]       │
   │     ↗                       │
   │   ↗    2020-2025実績        │
   │ ↗      2026-2030予測        │
   ├─────────────────────────────┤
   │ So What: 今が参入好機       │
   └─────────────────────────────┘
   ```

3. **ユーザー確認** - 「このイメージ図でOKですか？」

4. **スライド作成** - データ収集と原稿作成

5. **完成スライドの提示** - 実際の内容を確認

6. **ユーザー確認** - 「この内容でよろしいですか？修正が必要な箇所があれば教えてください」

7. **進捗更新** - ステータスを✅に変更、次へ進む確認

**成果物**: `[プロジェクト名]_演示稿_[日付].md`（全スライド統合版）

#### **フェーズ4: 仕上げ** (所要時間: 10-15分)
**何をするか**: 全体の整合性をチェックし、品質を確認します。

**チェック項目**:
- 論理性（メッセージとデータの一致）
- コンサル品質（So What、MECE、実行可能性）
- 視覚的品質（1スライド1図表、出所明記）
- データ品質（最新性、信頼性）
- フォーマット固有品質

### 3. スライド作成後

#### スライドイメージ図・フォーマット解説の出力

各スライド完成後、以下の追加情報を出力できます：

**出力できる情報**:
1. **スライドのイメージ図** - 視覚的なレイアウト構成
2. **フォーマット要素の解説** - 選択したフォーマット固有の特徴
3. **プレゼンテーション時のポイント** - 効果的な説明方法

**使い方**: スライド完成後に以下のように依頼します：
```
「第3枚目のイメージ図とプレゼンポイントを教えてください」
「このスライドのフォーマット要素を説明してください」
```

```markdown
## BCGフォーマット要素

このスライドには以下のBCG固有の要素が含まれています：

✓ **ストーリー重視のタイトル**
  - 数値を入れて具体性を持たせる
  - 「急成長」など感情に訴える言葉を使用

✓ **ビジュアル優先のデータ表現**
  - 複合グラフで複数情報を統合
  - 色彩とラベルで視線誘導

✓ **3つのキーポイント**
  - 数字を使って明確に（①②③）
  - 行動を促す具体的な洞察

  - 行動指向（「絶好機」）
  - ビジネスインパクトを明示

## プレゼンテーション時のポイント

### 導入 (15秒)
「市場環境について分析した結果をご説明します。」

**ポイント**: まずグラフ全体を見せて、全体像を把握してもらう

### メインメッセージ (30秒)
「このグラフが示すように、国内EC市場は年率15%で急成長しており、
2030年には30兆円に達する見込みです。」

**ポイント**: グラフの右上がりの部分を指しながら説明

### キーポイント展開 (45秒)
「特に注目すべき点が3つあります。」
- 「1点目、モバイルECの比率が既に70%を超えています」
- 「2点目、Z世代が市場拡大の主要ドライバーです」
- 「3点目、地方都市での成長が都市部を上回っています」

**ポイント**: 
- 各ポイントを順番に強調
- 数字は明確に発声
- 聴衆の反応を見ながらペース調整

### 結論 (15秒)
「これらのデータから、今が市場参入の絶好機であると言えます。」

**ポイント**: 
- 強い口調で断言
- 次のスライドへの橋渡し（「では、具体的な参入戦略を...」）

### 質疑応答への備え
**想定される質問**:
- Q: 「なぜ15%成長と言えるのか？」
  - A: 「過去5年間のCAGRが14.8%であり、デジタル化の加速を考慮すると...」
  
- Q: 「地方都市での成長要因は？」
  - A: 「物流インフラの整備とスマホ普及率の向上が主要因です」

### BCG流の話し方のコツ
1. **数字を前面に出す** - 「15%」「30兆円」を強調
2. **ストーリーで語る** - データの羅列ではなく、成長の物語として
3. **視覚とリンク** - 「このグラフの通り」と常に図を指す
4. **自信を持って** - BCGスタイルは断定的な表現を好む
```

**依頼方法**:
```
「第3枚目について、イメージ図、フォーマット要素、プレゼンポイントをまとめて出力してください」
```

### 4. Web検索機能

スキルは以下の情報を自動的にWeb検索します：

**検索対象**:
- **市場情報**: 市場規模、成長率、市場動向
- **競合情報**: 市場シェア、競合企業、企業業績
- **業界トレンド**: 業界動向、課題、規制
- **顧客情報**: 顧客ニーズ、消費者動向
- **ベンチマークデータ**: 業界標準指標、KPI

**データソースの優先順位**:
1. 政府統計（経済産業省、総務省など）
2. 業界団体レポート
3. 調査会社レポート（矢野経済研究所、富士経済など）
4. 主要メディア（日経、東洋経済など）
5. 企業IR資料

**データ収集の特徴**:
- フェーズ1で8-15件の初期情報収集
- 各スライドで3-8件の追加検索
- 出所URLを必ず記録
- 複数ソースでクロスチェック

- 通常のコンサルティング資料作成

## 使用例

### 例1: 新規市場参入の検討

```
ユーザー: 「東南アジア市場への参入を検討したい」

スキルの対応:
1. イシュー特定
   → 「どの国に、どの方法で参入すべきか？」

2. ケースパターン「新規市場参入」を参照

3. 5C、Porter 5 Forces を適用

4. Web検索で8-15件の市場データを収集

5. スライド構成設計（進捗ステータス付き）

6. Markdown形式でスライドを順次生成
   ⚫⚫⚫⚫⚫ → ✅📝⚫⚫⚫ → ✅✅✅✅✅

7. （オプション）PowerPointに変換
```

### 例2: 売上減少対策

```
ユーザー: 「売上が10%減少している。原因と対策を知りたい」

スキルの対応:
1. イシュー特定
   → 「売上減少の主要因は何で、どの対策が有効か？」

2. イシューツリーで分解
   売上減少 = 顧客数減少 + 客単価低下

3. 仮説立案
   仮説: 「競合の低価格攻勢が主因」

4. データ収集・分析で検証

5. ケースパターン「売上増加」「競合対策」を参照

6. 資料作成
```

## ベストプラクティス

### 課題構造化

- イシューは1文で明確に
- MECEに分解
- 目的・ゴール・成功基準を明文化

### 分析

- 仮説を先に立てる（網羅的分析は避ける）
- フレームワークを適切に選択
- データの出所を明記
- So What（示唆）を必ず導出

### 資料作成

- 1スライド1メッセージ
- 結論を先に
- ピラミッドストラクチャーで構成
- 品質チェックリストで確認

## 制約事項

- **言語**: 日本語のみ対応
- **データ収集**: Web検索が主。詳細な内部データが必要な場合はユーザーに依頼
- **フォーマット**: 標準テンプレートを提供。特定コンサルファームのフォーマットは要相談
