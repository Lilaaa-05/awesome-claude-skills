## 1. 新規市場参入

### 分析フレームワーク

#### Step 1: 市場魅力度分析
**使用フレームワーク**: 5C、Porter 5 Forces

```
【分析項目】
1. 市場規模・成長率
   - 現在の市場規模
   - 過去3-5年の成長率
   - 今後の成長予測

2. 顧客ニーズ
   - ターゲット顧客は誰か
   - どのようなニーズがあるか
   - ニーズは満たされているか

3. 競合状況
   - 主要競合は誰か
   - 市場シェア分布
   - 競争の激しさ

4. 業界構造
   - Porter 5 Forces で評価
   - 業界の収益性
```

**Web検索項目**:
- 「[業界名] 市場規模」
- 「[業界名] 成長率 予測」
- 「[業界名] 市場シェア」
- 「[業界名] 競合企業」

#### Step 2: 参入障壁評価

```
【参入障壁のチェック】
1. 資本障壁
   - 初期投資額
   - 資金調達の可能性

2. 規制障壁
   - 許認可の必要性
   - 規制の厳しさ

3. 技術障壁
   - 必要な技術・ノウハウ
   - 特許状況

4. ブランド障壁
   - 既存企業のブランド力
   - 顧客ロイヤルティ

5. 流通障壁
   - チャネル確保の難易度
   - 既存企業との関係
```

#### Step 3: 自社適合性評価

```
【自社の評価】
1. 既存資産の活用可能性
   - 技術・ノウハウ
   - 顧客基盤
   - ブランド

2. シナジー効果
   - 既存事業とのシナジー
   - クロスセル機会

3. リスク評価
   - 失敗時の影響
   - 撤退の容易さ
```

#### Step 4: 参入方法の比較

```
【参入方法の選択肢】

1. 自社展開（Organic Growth）
   ○ 完全なコントロール
   × 時間がかかる
   × リスクが大きい

2. M&A（買収）
   ○ スピードが速い
   ○ 既存の顧客・ノウハウを獲得
   × 高コスト
   × PMIの難しさ

3. 提携・JV
   ○ リスク分散
   ○ パートナーのノウハウ活用
   × 利益分配が必要
   × コントロールが限定的
```

### 意思決定フレーム

```
【GO / NO-GO の判断基準】

GO（参入すべき）:
✓ 市場魅力度が高い（規模・成長率）
✓ 参入障壁が適度（高すぎず低すぎず）
✓ 自社の強みが活かせる
✓ 期待収益 > リスク

NO-GO（参入すべきでない）:
× 市場魅力度が低い
× 参入障壁が高すぎる
× 自社の強みが活かせない
× リスクが大きすぎる
```

### アウトプット例

```markdown
# 新規市場参入の是非

## エグゼクティブサマリー
X市場への参入を推奨。市場は年率10%で成長しており、
自社の技術を活かせる。M&Aによる参入が最適。

## 市場魅力度
- 市場規模: 5,000億円
- 成長率: 年10%
- 競合: 中小企業中心、大手不在

## 参入障壁
- 資本: 中程度（50億円程度）
- 規制: 低い
- 技術: 自社保有技術で対応可能

## 推奨戦略
M&Aによる参入。ターゲット企業はA社（シェア10%、売上100億円）
```

## 2. 業界分析

### 分析フレームワーク

#### Step 1: 業界の現状分析

**使用フレームワーク**: Porter 5 Forces、PEST

```
【マクロ環境（PEST）】
Political: 規制動向、政策
Economic: 市場規模、成長率
Social: 顧客トレンド、人口動態
Technological: 技術革新

【競争環境（5 Forces）】
業界内競争、新規参入、代替品、買い手、売り手
```

#### Step 2: 主要プレイヤー分析

```
【競合比較】
| 企業 | シェア | 売上 | 強み | 戦略 |
|------|--------|------|------|------|
| A社  | 30%    | 3,000億| ブランド | プレミアム |
| B社  | 25%    | 2,500億| コスト | 低価格 |
| C社  | 20%    | 2,000億| 技術 | 差別化 |
```

#### Step 3: バリューチェーン分析

```
業界の価値連鎖を分析:

原材料 → 製造 → 流通 → 小売 → 消費者
   ↓       ↓      ↓      ↓
利益配分: 10%  20%  30%  40%

→ どこに利益が集中しているか
→ 自社はどこで勝負すべきか
```

#### Step 4: 将来展望

```
【今後3-5年の予測】
- 市場規模の予測
- 競争構造の変化
- 新技術の影響
- 規制の変化
```

## 3. M&A

### 分析フレームワーク

#### Step 1: 買収目的の明確化

```
【M&Aの目的】
1. 事業拡大（水平統合）
2. 新市場参入
3. 技術・人材獲得
4. サプライチェーン統合（垂直統合）
5. シナジー創出
```

#### Step 2: ターゲット企業の評価

**使用フレームワーク**: 3C、SWOT、財務分析

```
【評価項目】

1. 戦略的適合性
   - 自社戦略との整合性
   - シナジー効果

2. 財務評価
   - 収益性（売上、利益、利益率）
   - 成長性（売上成長率）
   - 健全性（負債比率、流動性）

3. 非財務評価
   - 顧客基盤
   - 技術・ノウハウ
   - 人材
   - ブランド

4. リスク評価
   - 顧客集中リスク
   - キーパーソン依存
   - 訴訟・コンプライアンス
```

#### Step 3: バリュエーション（企業価値算定）

```
【算定方法】

1. DCF法（Discounted Cash Flow）
   企業価値 = 将来キャッシュフローの現在価値

2. 類似企業比較法
   企業価値 = EBITDA × 業界平均倍率

3. 純資産法
   企業価値 = 純資産の時価

【買収価格の決定】
企業価値 + プレミアム - 負債 = 買収価格
```

#### Step 4: デューデリジェンス

```
【確認事項】

財務DD:
- 財務諸表の適正性
- 簿外債務の有無
- 税務リスク

ビジネスDD:
- 市場・競合状況
- 顧客・契約状況
- 事業計画の妥当性

法務DD:
- 訴訟リスク
- 契約関係
- 知的財産権

人事DD:
- 組織体制
- キーパーソン
- 労務問題
```

#### Step 5: PMI（Post Merger Integration）

```
【統合計画】

Day 1（初日）:
- 統合チーム発足
- 従業員への説明

100日プラン:
- クイックウィン施策
- システム統合着手
- 組織体制の決定

1年プラン:
- 完全統合
- シナジー実現
- 文化統合
```

### 意思決定フレーム

```
【GO / NO-GO】

GO:
✓ 戦略的に意義がある
✓ バリュエーションが適正
✓ DDで重大な問題なし
✓ PMIが実行可能

NO-GO:
× 価格が高すぎる
× DDで重大リスク発見
× PMI が困難
```

**使用フレームワーク**: STP、3C

```
【ターゲット顧客】
- Who: 誰に

【差別化ポイント】
- 既存商品との違い

```

```
【市場規模推計】

潜在顧客数 × 購買率 × 購買単価 × 購買頻度

【競合分析】
- 類似商品の存在
- 競合の価格帯
- 競合の販売実績
```

**使用フレームワーク**: 4P

```
Product:
- 商品スペック

- ブランド名

Price:
- 価格設定（競合比較、コストベース、価値ベース）
- 価格戦略（プレミアム、浸透価格など）

Place:
- 販売チャネル（EC、店舗、卸）
- 流通戦略

Promotion:
- 広告戦略
- PR戦略
- キャンペーン
```

#### Step 4: 事業計画

```
【売上計画】
Year 1: 10億円
Year 2: 30億円
Year 3: 50億円

【損益計画】
売上 - 売上原価 - 販管費 = 営業利益
Year 1: 黒字化
Year 3: 利益率10%達成

【投資計画】
- 開発費: 5億円
- マーケティング費: 3億円
- 初期在庫: 2億円
合計: 10億円
```

## 5. 価格戦略

### 分析フレームワーク

#### 価格設定の3つのアプローチ

**1. コストベース価格設定**
```
価格 = コスト × (1 + 目標利益率)

例:
製造コスト: 5,000円
目標利益率: 30%
→ 価格 = 5,000円 × 1.3 = 6,500円
```

**2. 競合ベース価格設定**
```
競合価格を基準に設定

- 同等品質: 競合と同価格
- 高品質: 競合 + 10-20%
- 低品質/高効率: 競合 - 10-20%
```

**3. 価値ベース価格設定**
```
顧客が感じる価値に基づいて設定

例:
- 顧客が得る便益: 年100万円のコスト削減
- 競合の価格: 30万円
→ 価格: 50万円（便益の50%、競合比+66%）
```

#### 価格戦略の選択

```
【プレミアム価格戦略】
適用: 高品質、ブランド力がある
メリット: 高利益率
リスク: 数量が伸びない

【市場浸透価格戦略】
適用: シェア拡大が目的
メリット: 早期にシェア獲得
リスク: 利益率が低い、後の値上げが困難

【スキミング価格戦略】
適用: 新技術、独自性が高い
メリット: 初期に高利益
戦略: 徐々に価格を下げる

【ダイナミックプライシング】
適用: 需要変動が大きい
手法: 需要に応じてリアルタイムで価格変更
例: 航空券、ホテル、イベントチケット
```

## 6. 成長戦略

### 分析フレームワーク

#### Ansoffの成長マトリクス

```
         既存製品    新製品
      ┌─────┬─────┐
既存市場│市場浸透│製品開発│
      ├─────┼─────┤
新市場 │市場開拓│多角化  │
      └─────┴─────┘
```

**1. 市場浸透（Market Penetration）**
```
既存市場 × 既存製品

施策:
- シェア拡大
- 使用頻度増加
- 新規顧客獲得

リスク: 低
リターン: 低～中
```

**2. 製品開発（Product Development）**
```
既存市場 × 新製品

施策:
- 新商品投入
- 既存商品の改良
- ラインナップ拡大

リスク: 中
リターン: 中
```

**3. 市場開拓（Market Development）**
```
新市場 × 既存製品

施策:
- 地域拡大（海外展開）
- 新顧客セグメント開拓
- 新チャネル開拓

リスク: 中
リターン: 中～高
```

**4. 多角化（Diversification）**
```
新市場 × 新製品

種類:
- 関連多角化: 既存事業とシナジーあり
- 非関連多角化: 全く新しい事業

リスク: 高
リターン: 高（成功すれば）
```

#### 成長戦略の評価

```
【評価基準】
1. 市場魅力度
2. 自社の強みの活用度
3. リスクとリターンのバランス
4. 投資額
5. 実現可能性

【推奨】
まず市場浸透、次に製品開発または市場開拓、
最後に多角化（リスク高いため慎重に）
```

## 7. 起業・新規事業立ち上げ

### 分析フレームワーク

#### Step 1: 事業アイデアの検証

**使用フレームワーク**: Lean Canvas

```
【Lean Canvas 9項目】

1. 課題（Problem）
   - 顧客の抱える課題は？

2. 顧客セグメント（Customer Segments）
   - ターゲット顧客は誰？

3. 独自の価値提案（Unique Value Proposition）
   - なぜ顧客は選ぶのか？

4. ソリューション（Solution）
   - どう解決するか？

5. チャネル（Channels）
   - どう届けるか？

6. 収益の流れ（Revenue Streams）
   - どう収益化するか？

7. コスト構造（Cost Structure）
   - 主なコストは？

8. 主要指標（Key Metrics）
   - 何を測定するか？

9. 圧倒的な優位性（Unfair Advantage）
   - 真似できない強みは？
```

#### Step 2: 市場検証（MVP）

```
【MVP（Minimum Viable Product）】
最小限の機能で市場検証

手順:
1. 仮説設定
2. MVP作成
3. 顧客テスト
4. フィードバック収集
5. ピボット or 継続
```

#### Step 3: 事業計画策定

```
【事業計画の構成】

1. エグゼクティブサマリー
2. 事業概要
3. 市場分析
4. 競合分析
5. 製品・サービス
6. マーケティング戦略
7. オペレーション計画
8. 経営チーム
9. 財務計画（3-5年）
10. リスクと対策
```

#### Step 4: 資金調達（VC視点の分析）

```
【VCが見るポイント】

1. 市場規模（TAM: Total Addressable Market）
   - 最低でも1,000億円以上

2. トラクション（成長性）
   - ユーザー数の増加率
   - 売上の成長率

3. チーム
   - 創業者の経験・実績
   - チームの補完性

4. プロダクト
   - 差別化
   - 防御可能性

5. ユニットエコノミクス
   - LTV（顧客生涯価値） > CAC（顧客獲得コスト）
```

## 8. 競合対策

### 分析フレームワーク

#### Step 1: 競合の動き分析

```
【競合の動きを把握】
- 新商品発売
- 価格変更
- 広告キャンペーン
- 提携・M&A
- 新拠点開設
```

#### Step 2: 影響評価

```
【自社への影響】
- 売上への影響（-10%など）
- シェアへの影響
- ブランドへの影響
- 顧客への影響
```

#### Step 3: 対抗策の立案

```
【対抗策の選択肢】

1. 価格対抗
   ○ 即効性がある
   × 利益率低下

2. 製品差別化
   ○ 持続的優位
   × 時間がかかる

3. サービス強化
   ○ 顧客ロイヤルティ向上
   × 投資が必要

4. マーケティング強化
   ○ ブランド価値向上
   × コストがかかる

5. 無視（何もしない）
   ○ コストゼロ
   × シェア低下リスク
```

#### Step 4: 実行と モニタリング

```
【KPIの設定】
- シェアの推移
- 売上の推移
- 顧客満足度
- ブランド認知度

【定期レビュー】
月次でKPIをモニタリングし、必要に応じて戦略修正
```

## 9. 売上増加

### 分析フレームワーク

#### 売上の分解

```
売上 = 顧客数 × 購買頻度 × 客単価

または

売上 = 新規顧客売上 + 既存顧客売上
```

#### 売上増加の施策

**1. 顧客数を増やす**
```
新規顧客獲得:
- 広告強化
- 新チャネル開拓
- 紹介プログラム

既存顧客維持:
- ロイヤルティプログラム
- カスタマーサポート強化
```

**2. 購買頻度を増やす**
```
- リマインドメール
- サブスクリプション化
- ポイントプログラム
- 定期購入割引
```

**3. 客単価を増やす**
```
- アップセル（上位商品提案）
- クロスセル（関連商品提案）
- バンドル販売
- 値上げ
```

## 10. コスト削減

### 分析フレームワーク

#### Step 1: コスト構造の分析

```
コスト = 固定費 + 変動費

【固定費】
- 人件費
- 家賃
- 減価償却費
- その他間接費

【変動費】
- 原材料費
- 外注費
- 販売手数料
```

#### Step 2: 削減機会の特定

**使用フレームワーク**: Value Chain、ABC分析

```
【ABC分析】
A: コストの80%を占める20%の項目 → 優先的に削減
B: 中程度
C: コストが小さい項目 → 後回し
```

#### Step 3: 削減施策

```
【施策の例】

1. 調達コスト削減
   - サプライヤー見直し
   - 大量購入によるボリュームディスカウント
   - 競争入札

2. 製造コスト削減
   - 工程改善
   - 自動化
   - 歩留まり向上

3. 間接費削減
   - オフィス面積削減
   - 業務効率化
   - アウトソーシング

4. 人件費適正化
   - 業務効率化による残業削減
   - 組織のスリム化
   - 配置最適化
```

#### Step 4: 実行計画

```
【優先順位づけ】
- 削減効果（大 / 中 / 小）
- 実行容易性（易 / 中 / 難）
- 実行期間（短期 / 中期 / 長期）

【クイックウィン】
効果大 × 容易 → 即実行
```

## 11. 利益増加

### 分析フレームワーク

#### 利益の分解

```
営業利益 = 売上 - 売上原価 - 販管費
        = (単価 × 販売量) - (変動費 × 販売量 + 固定費) - 販管費
```

#### 利益増加の施策

**1. 売上を増やす** → ケース9参照

**2. 原価を下げる** → ケース10参照

**3. 販管費を下げる** → ケース10参照

**4. ミックスを改善する**
```
商品ミックス:
- 高利益率商品の販売比率を上げる
- 低利益率商品の販売比率を下げる

顧客ミックス:
- 高収益顧客に注力
- 低収益顧客を整理
```

#### 統合的アプローチ

```
【優先順位】
1. クイックウィン施策（即効性）
2. 構造改善施策（持続性）
3. 成長投資（将来）

【バランス】
短期利益 vs 長期成長のバランスを取る
```
