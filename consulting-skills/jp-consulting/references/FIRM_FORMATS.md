# コンサルティングファーム別スライドデザインガイド

このガイドでは、各ファームの**スライドデザイン構成**を具体的に記載しています:
- **レイアウト**: グリッド構成、要素の配置方法
- **配色**: メインカラー、アクセントカラー、背景色
- **タイポグラフィ**: フォント種類、サイズ、使い方
- **ビジュアル**: チャート・図表の種類と表現方法
- **強調**: 重要情報の際立たせ方

## スライドデザイン適用のポイント

### 一貫性の確保
- **配色**: 選択したファームの指定色を全スライドで統一
- **タイポグラフィ**: フォント、サイズ、行間を統一
- **レイアウトグリッド**: 同じグリッドシステムを使用
- **ビジュアルスタイル**: チャート・図表のデザインを統一

### レイアウト構成の基本

各スライドは以下の要素で構成:

1. **ヘッダー部** (上部15-20%)
   - スライドタイトル
   - セクション名（オプション）
   - ページ番号

2. **メインコンテンツ部** (中央60-70%)
   - キーメッセージ
   - データビジュアライゼーション
   - 図表・チャート
   - 箇条書き・説明文

3. **フッター部** (下部5-10%)
   - 出所・注釈
   - 日付・機密性表示
   - ファームロゴ（該当する場合）


### カスタマイズの許容
- ファームの特徴を参考にしつつ、プロジェクトに最適化
- 聴衆や目的に応じて調整
- 複数フォーマットの良い点を選択的に活用

### 品質基準
どのフォーマットでも以下は必須:
- **1スライド1メッセージ**: 各スライドに明確な主張を1つ
- **データの出所明記**: 全てのデータに出典を記載
- **論理的な構成**: So What? Why So?が明確
- **実行可能な提言**: 具体的なアクションを提示
- **適切な余白**: 情報過多を避ける（スライド面積の30-40%は余白）

## スライドデザイン実装例

### 例1: 市場参入プロジェクト（BCGフォーマット）
```
ユーザー: 「東南アジア市場への参入戦略をBCG形式で」

→ BCGスライドデザイン適用

【レイアウト】
- 左カラム: キーメッセージ + 市場機会の説明
- 右カラム: 市場規模グラフ + 成長予測

【配色】
- グリーン(#00A758)でポジティブな成長を強調
- グラデーション背景で視覚的インパクト

【ビジュアル】
- 東南アジア地図にバブルチャート重ね合わせ
- アイコンで各国の特徴を表現
- インフォグラフィックで参入ステップを表示

【フォント】
- 見出し: Roboto Bold 24pt
- 本文: Roboto Regular 14pt
```

### 例2: ERPシステム導入（Abeamフォーマット）
```
ユーザー: 「ERPシステム導入提案をAbeam形式で」

→ Abeamスライドデザイン適用

【レイアウト】
- 横展開のフロー図でPhase別に配置
- 下部に詳細表を配置

【配色】
- ネイビー(#003366)で安定感
- オレンジ(#FF6600)でマイルストーン強調

【ビジュアル】
- ガントチャートで実装スケジュール
- システム構成図（現状→移行→目標）
- チェックリスト形式のタスク一覧

【フォント】
- 見出し: 游ゴシック Bold 20pt
- 本文: 游ゴシック Regular 13pt
- 表内: 游ゴシック 11pt
```


### 例3: 市場分析報告（NRIフォーマット）
```
ユーザー: 「市場分析報告書をNRI形式で」

→ NRIスライドデザイン適用

【レイアウト】
- アカデミックな論文スタイル
- 上部: タイトルと要旨
- 中央: 大きなグラフ・表
- 下部: 詳細な注釈・出典

【配色】
- 紺(#003C71)と青(#0066CC)のグラデーション
- データ系列は青系統で統一

【ビジュアル】
- 複合チャート（折れ線+棒グラフ）
- 回帰分析の散布図と近似曲線
- 予測範囲のシャドウ表示
- 統計的有意性マーク（*p<0.05）

【フォント】
- 見出し: 游明朝 Medium 18pt
- 本文: 游明朝 Regular 12pt
- 注釈: 游明朝 Regular 10pt

【データ表現】
- 脚注番号で詳細な出典明記
- 95%信頼区間の表示
- サンプル数の明記
```
