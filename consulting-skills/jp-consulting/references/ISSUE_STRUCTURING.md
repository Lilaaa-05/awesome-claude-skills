## 1. イシューとは

**イシュー（Issue）**: 「答えを出す必要のある問い」

### 良いイシューの3条件

1. **本質的（Material）**
   - その問いに答えが出れば、意思決定できる
   - 経営層が気にしている
   - 実行につながる

2. **深い（Deep）**
   - 表面的な問いではない
   - 本質的な因果関係に迫る
   - 「なぜ？」を3回繰り返した先にある

3. **答えが出せる（Answerable）**
   - 調査・分析可能
   - 現実的な時間とリソースで検証できる
   - データが入手可能

### 悪いイシューの例

❌ 「売上を上げるにはどうすればいいか？」
- 広すぎる、分解されていない

❌ 「従業員の満足度を上げるべきか？」
- 本質的でない（手段の話）

❌ 「10年後の市場はどうなるか？」
- 答えが出せない（不確実性が高すぎる）

### 良いイシューの例

✅ 「A市場への参入は、B市場への参入より収益性が高いか？」
- 本質的、比較可能、答えが出せる

✅ 「価格を10%下げた場合、販売量は何%増加するか？」
- 深い、具体的、検証可能

✅ 「現在の営業プロセスのどこにボトルネックがあるか？」
- 本質的、分析可能、アクショナブル

## 2. イシューの特定プロセス

### Step 1: ユーザーの発言から真の課題を抽出

ユーザーの言葉をそのまま受け取らず、背景を掘り下げる：

```
ユーザー: 「売上が伸び悩んでいます」
↓ 掘り下げ
- なぜ売上が重要なのか？（収益性？シェア？）
- 何と比較して伸び悩んでいるのか？（目標？競合？）
- いつから？どの製品・地域で？
```

**質問例**:
- 「このプロジェクトで最も重要な意思決定は何ですか？」
- 「どのような状態になれば成功と言えますか？」
- 「現在、何がボトルネックになっていますか？」

### Step 2: イシューを1文で表現

明確で、具体的な問いの形式にする：

```
形式: 「〇〇すべきか？」「〇〇と〇〇のどちらが良いか？」「〇〇の原因は何か？」

例:
- 「X市場に今年中に参入すべきか？」
- 「価格を下げるべきか、付加価値を上げるべきか？」
- 「売上減少の主要因は市場縮小か、競合流出か？」
```

### Step 3: 複数イシュー候補の優先順位付け

複数のイシューがある場合、以下の基準で優先度を決定：

| 基準 | 説明 |
|------|------|
| **インパクト** | 答えが出た時の意思決定への影響度 |
| **緊急性** | いつまでに答えが必要か |
| **実現可能性** | データ収集・分析の難易度 |

**優先度マトリクス**:
```
     高インパクト
        ↑
    [A] │ [B]
    優先 │ 重要
─────┼─────→ 高実現可能性
    [C] │ [D]
    保留 │ 後回し
```

## 3. イシューツリーの構築

メインイシューをMECEに分解する。

### MECEの原則

**MECE (Mutually Exclusive, Collectively Exhaustive)**:
- **Mutually Exclusive**: 要素が重複しない
- **Collectively Exhaustive**: 要素が漏れなく網羅

### イシューツリーの構造

```
[メインイシュー: A市場に参入すべきか？]
│
├─ [サブイシュー1: 市場は魅力的か？]
│  ├─ 市場規模はどの程度か？
│  ├─ 成長率はどうか？
│  └─ 収益性は高いか？
│
├─ [サブイシュー2: 参入障壁は低いか？]
│  ├─ 規制・法的障壁はあるか？
│  ├─ 技術的障壁はあるか？
│  └─ 資本障壁はあるか？
│
└─ [サブイシュー3: 自社の強みは活かせるか？]
   ├─ 既存の技術・ノウハウは活かせるか？
   ├─ 既存顧客基盤は活かせるか？
   └─ ブランド力は通用するか？
```

### MECE分解のパターン

#### パターン1: プロセス分解
```
売上増加の方法は？
├─ 新規顧客獲得
├─ 既存顧客維持
└─ 顧客単価向上
```

#### パターン2: 要因分解
```
利益減少の原因は？
├─ 売上減少
│  ├─ 販売量減少
│  └─ 価格低下
└─ コスト増加
   ├─ 固定費増加
   └─ 変動費増加
```

#### パターン3: セグメント分解
```
どの地域に注力すべきか？
├─ 東アジア
├─ 東南アジア
├─ 南アジア
└─ その他アジア
```

#### パターン4: 時系列分解
```
新商品投入のタイミングは？
├─ 短期（～6ヶ月）
├─ 中期（6ヶ月～2年）
└─ 長期（2年～）
```

### イシューツリー構築の手順

1. **メインイシューを確定**
2. **第1階層でMECE分解**（通常2-4個）
3. **各サブイシューをさらに分解**（必要に応じて）
4. **MECE チェック**：
   - 重複はないか？
   - 漏れはないか？
   - 適切な粒度か？

## 4. 目的・ゴールの文書化

プロジェクトの方向性を明確にするため、以下を文書化：

### プロジェクト目的

**Why**: なぜこの分析が必要か

```
例:
- A市場への参入可否を判断するため
- 現状の利益減少の原因を特定し、対策を立案するため
- 3年後の成長戦略を策定するため
```

### 成果物のゴール

**What**: 何を意思決定するための材料か

```
例:
- 経営会議でA市場参入の承認を得る
- 来期の利益改善施策を決定する
- 中期経営計画に成長戦略を反映する
```

### 成功基準

**How to Measure**: 何が達成されれば成功か

```
例:
- 参入可否の明確な推奨が提示されている
- 利益改善の具体的施策と期待効果が示されている
- 経営層が戦略的意思決定を行える材料が揃っている
```

### スコープの明確化

**In Scope（含む）**:
```
例:
- A市場の市場規模・成長性分析
- 主要競合3社の分析
- 参入方法の比較（自社展開 vs M&A vs 提携）
```

**Out of Scope（含まない）**:
```
例:
- B市場、C市場の詳細分析
- 参入後の詳細な事業計画
- 具体的な組織体制の設計
```

## 5. 課題構造化チェックリスト

プロジェクト開始前に以下を確認：

**イシュー品質**:
- [ ] イシューは1文で明確に表現されているか
- [ ] 答えが出れば意思決定できるか（本質的か）
- [ ] 表面的でなく、本質に迫っているか（深いか）
- [ ] 現実的に答えを出せるか（実行可能か）

**イシューツリー品質**:
- [ ] MECEに分解されているか
- [ ] 重複はないか
- [ ] 漏れはないか
- [ ] 適切な粒度か（細かすぎず、粗すぎず）

**プロジェクト定義**:
- [ ] 目的が明確か
- [ ] ゴールが具体的か
- [ ] 成功基準が測定可能か
- [ ] スコープが明確か

## 6. 実践例

### 例1: 新規市場参入

**ユーザーの問い**: 「東南アジア市場に進出したいが、どうすればいいか？」

**イシュー特定**:
```
[メインイシュー]
「東南アジアのどの国に、どのような方法で参入すべきか？」

[イシューツリー]
├─ どの国が最も魅力的か？
│  ├─ 市場規模・成長性
│  ├─ 参入障壁
│  └─ 競合状況
│
├─ どの参入方法が最適か？
│  ├─ 自社展開
│  ├─ M&A
│  └─ 現地企業との提携
│
└─ 参入タイミングはいつが良いか？
   ├─ 即時参入
   ├─ 1-2年後
   └─ 3年以降
```

### 例2: 売上減少対策

**ユーザーの問い**: 「売上が減っています。何とかしてください」

**イシュー特定**:
```
[メインイシュー]
「売上減少の主要因は何で、どの対策が最も効果的か？」

[イシューツリー]
├─ 売上減少の主要因は？
│  ├─ 市場全体の縮小か？
│  ├─ 競合への顧客流出か？
│  └─ 自社製品の魅力低下か？
│
├─ 各要因への対策は？
│  ├─ 新市場開拓
│  ├─ 差別化強化
│  └─ 商品力向上
│
└─ 最も効果的な対策は？
   └─ 費用対効果、実現可能性、期間
```

## 7. よくある失敗パターン

### 失敗1: イシューが広すぎる

❌ 「当社の課題は何か？」
✅ 「売上減少の主要因は市場縮小か、競合流出か？」

### 失敗2: イシューが手段になっている

❌ 「Webサイトをリニューアルすべきか？」
✅ 「顧客獲得コストを下げるには、Web改善か、広告最適化か？」

### 失敗3: MECEでない分解

❌ 売上改善策
   - 新規顧客獲得
   - 既存顧客維持
   - Webマーケティング強化  ← 新規獲得と重複

✅ 売上改善策
   - 新規顧客獲得
   - 既存顧客維持
   - 顧客単価向上

### 失敗4: 詳細すぎる分解

```
❌ 第4階層まで分解
   - 分析が発散する
   - 全体像が見えなくなる

✅ 第2-3階層まで
   - 適度な粒度を保つ
   - 必要に応じて後で深掘り
```

## 8. ツール・テンプレート

### イシュー特定シート

```markdown
## イシュー特定シート

### 背景・状況
[ユーザーの置かれている状況]

### ユーザーの発言
[ユーザーが最初に言った問い]

### 真の課題（仮説）
[掘り下げた結果、見えてきた真の課題]

### メインイシュー
[1文で明確に表現]

### 本質的か？
[Yes/No + 理由]

### 深いか？
[Yes/No + 理由]

### 答えが出せるか？
[Yes/No + 理由]
```

### イシューツリーテンプレート

```markdown
## イシューツリー

### メインイシュー
[問いを記述]

### 第1階層（MECE分解）
1. [サブイシュー1]
2. [サブイシュー2]
3. [サブイシュー3]

### 第2階層（各サブイシューの分解）

#### サブイシュー1
- [論点1-1]
- [論点1-2]
- [論点1-3]

#### サブイシュー2
- [論点2-1]
- [論点2-2]

#### サブイシュー3
- [論点3-1]
- [論点3-2]
```
