## 1. フェルミ推定とは

### 定義
少ない情報から、論理的な仮定を積み重ねて概算値を求める手法

### 用途
- 市場規模の推計
- 潜在顧客数の算出
- 売上予測
- コスト概算

### メリット
- データがなくても概算できる
- 短時間で答えが出る
- ビジネス感覚が養われる

## 2. フェルミ推定の基本ステップ

### Step 1: 問題の定義

```
例: 「日本のコーヒー市場規模は？」

明確化:
- 対象: 日本国内
- 製品: コーヒー（豆、レギュラー、インスタント、缶コーヒー含む）
- 期間: 年間
```

### Step 2: アプローチの決定

```
【トップダウン】
大きな数字から分解

【ボトムアップ】
小さな単位から積み上げ
```

### Step 3: 要素の分解

```
市場規模 = 人口 × 比率 × 単価 × 頻度
```

### Step 4: 各要素の推定

```
人口: 1.2億人
コーヒー飲用率: 80%
年間消費回数: 200回
平均単価: 300円
```

### Step 5: 計算

```
1.2億人 × 80% × 200回 × 300円
= 5,760億円
```

### Step 6: 検証

```
公表データと比較:
実際の市場規模: 約6,000億円
→ 概ね合っている
```

## 3. フェルミ推定のパターン

### パターン1: 市場規模推計

#### トップダウン型
```
日本のコーヒー市場規模

= 日本の人口
  × コーヒーを飲む人の比率
  × 1人あたり年間消費回数
  × 平均単価

= 1.2億人 × 80% × 200回 × 300円
= 5,760億円
```

#### ボトムアップ型
```
日本のコーヒー市場規模

= 家庭消費 + 外出先消費

家庭消費:
= 世帯数 × 飲用世帯率 × 年間購入額
= 5,000万世帯 × 90% × 6,000円
= 2,700億円

外出先消費:
= カフェ + 缶コーヒー + 自販機
= 1,500億円 + 1,000億円 + 500億円
= 3,000億円

合計: 5,700億円
```

### パターン2: 顧客数推計

```
あるサービスの潜在顧客数

= 総人口
  × ターゲット年齢層の比率
  × ニーズを持つ人の比率
  × 購買力のある人の比率

= 1.2億人 × 30%（20-40代） × 50%（ニーズあり） × 70%（購買力）
= 1,260万人
```

### パターン3: 売上予測

```
新商品の初年度売上

= 潜在顧客数
  × 認知率
  × 購買率
  × 平均購買額

= 1,000万人 × 20%（認知） × 10%（購買） × 5,000円
= 10億円
```

### パターン4: 店舗数推計

```
日本のコンビニ店舗数

= 日本の人口 / 1店舗あたりカバー人数

= 1.2億人 / 2,000人
= 6万店

（実際: 約5.5万店）
```

## 6. 実践例

### 例1: ラーメン店の売上推計

```
【問い】
駅前のラーメン店の月間売上は？

【推定】
座席数: 20席
営業時間: 11:00-23:00（12時間）
回転率: ランチ4回転、ディナー2回転

ランチ売上:
20席 × 4回転 × 800円 × 30日
= 192万円

ディナー売上:
20席 × 2回転 × 1,200円 × 30日
= 144万円

合計: 約340万円/月
```

### 例2: 美容室の市場規模

```
【問い】
日本の美容室市場規模は？

【推定】
人口: 1.2億人
美容室利用率: 80%（女性90%、男性70%）
年間利用回数: 5回
平均単価: 5,000円

市場規模:
1.2億人 × 80% × 5回 × 5,000円
= 2.4兆円

（実際: 約2.5兆円）
```

### 例3: フィットネスクラブ会員数

```
【問い】
日本のフィットネスクラブ会員数は？

【推定】
人口: 1.2億人
ターゲット: 20-60代（60%）
健康志向層: 30%
実際に入会: 15%

会員数:
1.2億人 × 60% × 30% × 15%
= 324万人

（実際: 約300万人）
```

### 例4: 電気自動車の2030年販売台数

```
【問い】
2030年の日本EV販売台数は？

【推定】
新車販売台数: 400万台（現状維持と仮定）

EV販売台数:
400万台 × 30% = 120万台

楽観シナリオ（50%）: 200万台
悲観シナリオ（15%）: 60万台
```

## 7. 精度を上げるコツ

### 1. 複数アプローチで検証

```
トップダウンとボトムアップの両方で計算し、
結果が近ければ信頼性が高い
```

### 2. セグメントを分ける

```
全体をまとめて計算するより、
セグメント別に計算して合算する方が正確

例:
コーヒー市場 = 家庭 + カフェ + 缶コーヒー + 自販機
```

### 3. 現実的な数字を使う

```
× 飲用率100% → 現実的でない
◯ 飲用率80% → 妥当
```

### 4. オーダー（桁）を合わせる

```
フェルミ推定の目的は、
「5,678億円」ではなく、
「約5,000-6,000億円」の概算値を出すこと
```

### 5. 前提条件を明示

```
【前提】
- 人口: 1.2億人（2024年時点）
- 飲用率: 80%（自社調査に基づく）
- 平均単価: 300円（店舗・EC・自販機の加重平均）

前提が変われば結果も変わることを明示
```

## 8. よくある間違い

### 間違い1: 過度に細かく計算

```
× 1.23456789億人 × 79.8% × 198.7回...
→ 意味のない精度

◯ 約1.2億人 × 80% × 200回...
→ 適切な概算
```

### 間違い2: 非現実的な仮定

```
× 全国民がコーヒーを飲む（100%）
→ 赤ちゃんや子供は飲まない

◯ 成人の80%程度
→ 現実的
```

### 間違い3: 単位の間違い

```
× 1.2億人 × 200回 × 300円 = 7.2兆円
→ 計算ミス（単位の誤り）

◯ 1.2億人 × 200回 × 300円 = 7,200億円
→ 正しい
```

### 間違い4: 検証しない

```
推定結果が出たら、公表データや常識と照らし合わせて
妥当性を確認する
```

## 9. ビジネスへの応用

### 新規事業の市場規模推計

```
【ステップ】
1. TAM（Total Addressable Market）を推計
   → フェルミ推定で全体市場

2. SAM（Serviceable Available Market）を推計
   → ターゲットセグメントに絞る

3. SOM（Serviceable Obtainable Market）を推計
   → 自社が獲得可能なシェア

【例: オンラインヨガサービス】
TAM: フィットネス市場全体 2.5兆円
SAM: ヨガ人口 × 平均支出 = 500億円
SOM: SAM × 目標シェア5% = 25億円
```

### 投資判断

```
市場規模が大きいか？
→ フェルミ推定で確認

成長性はあるか？
→ 過去データと今後の推定

自社シェア×%取れるか？
→ 期待売上を算出
```

### クイック分析

```
詳細なデータがない段階で、
「大体このくらい」を把握するために活用

例:
「この新規事業、市場規模どのくらい?」
→ フェルミ推定で「約〇〇億円」と即答
```

## 11. 解答例

### 問題1解答: 傘の販売本数

```
人口: 1.2億人
1人あたり保有本数: 3本
買い替えサイクル: 2年

年間販売本数:
1.2億人 × 3本 / 2年
= 1.8億本/年

（ビニール傘などの使い捨て需要を加えると2-3億本）
```

### 問題2解答: 東京のタクシー台数

```
東京の人口: 1,400万人
1台あたりカバー人数: 300人

タクシー台数:
1,400万人 / 300人
= 約4.7万台

（実際: 約5万台）
```

### 問題3解答: スターバックス売上

```
店舗数: 1,700店
営業時間: 12時間
1店舗あたり客数: 600人/日
客単価: 600円
営業日数: 350日

年間売上:
1,700店 × 600人 × 600円 × 350日
= 約2,140億円

（実際: 約2,000億円）
```

### 問題4解答: 結婚式場市場

```
年間婚姻件数: 50万組
結婚式を挙げる割合: 60%
平均費用: 350万円

市場規模:
50万組 × 60% × 350万円
= 1.05兆円

（実際: 約1.5兆円 ※披露宴、二次会含む）
```

## 12. まとめ

### フェルミ推定のポイント

✓ 完璧な精度を求めない（桁が合えばOK）
✓ 現実的な仮定を使う
✓ 複数アプローチで検証
✓ 前提条件を明示
✓ 公表データと照合

### 活用シーン

- 市場規模の概算が必要な時
- データがない時
- 素早く判断が必要な時
- ビジネスアイデアの検証時

### 練習方法

日常で練習:
- 「このレストランの年間売上は?」
- 「この駅の1日の乗降客数は?」
- 「日本の◯◯の市場規模は?」

→ 推定後、実際のデータで答え合わせ
