## 1. MECE・ロジックツリー

### MECEとは

**MECE (Mutually Exclusive, Collectively Exhaustive)**:
- Mutually Exclusive: 重複がない
- Collectively Exhaustive: 漏れがない

### MECE分解のパターン

#### パターン1: 対立概念
```
全体
├─ 内部 / 外部
├─ 定量 / 定性
├─ 短期 / 長期
└─ ハード / ソフト
```

#### パターン2: プロセス
```
全体
├─ インプット
├─ プロセス
└─ アウトプット
```

#### パターン3: セグメント
```
売上
├─ 商品A
├─ 商品B
└─ 商品C
```

#### パターン4: 数式
```
利益 = 売上 - コスト
├─ 売上 = 単価 × 販売量
└─ コスト = 固定費 + 変動費
```

### ロジックツリーの種類

#### What ツリー（問題特定）
```
売上減少
├─ 販売量減少
│  ├─ 新規顧客減少
│  └─ 既存顧客離反
└─ 単価低下
   ├─ 値下げ
   └─ 商品構成変化
```

#### Why ツリー（原因分析）
```
なぜ売上が減ったのか？
├─ なぜ新規顧客が減ったのか？
│  ├─ 広告効果が低下
│  └─ 市場認知度が低下
└─ なぜ既存顧客が離反したのか？
   ├─ 商品品質の問題
   └─ サービスの問題
```

#### How ツリー（解決策）
```
売上を増やすには？
├─ 新規顧客を獲得する
│  ├─ 広告を強化
│  └─ 新チャネル開拓
└─ 既存顧客を維持する
   ├─ 品質向上
   └─ サービス改善
```

### 適用手順

1. **目的を明確化**（What/Why/Howのどれか）
2. **第1階層でMECE分解**
3. **第2階層でさらに分解**
4. **MECEチェック**
5. **重要論点の特定**

## 2. 3C分析

顧客・競合・自社の3つの視点で市場・事業を分析。

### 3Cの構成

```
┌─────────────┐
│   Customer   │ ← 顧客
│   (市場)     │
└──────┬──────┘
       │
   ┌───┴───┐
   │       │
┌──▼────┐ ┌▼─────┐
│Company│ │Competitor│
│(自社) │ │(競合)   │
└───────┘ └──────┘
```

### Customer（顧客・市場）

#### 分析項目
- **市場規模**: 現在の市場規模、成長率
- **顧客セグメント**: 年齢、性別、所得、地域
- **顧客ニーズ**: 何を求めているか
- **購買行動**: いつ、どこで、どう買うか
- **市場トレンド**: 将来の変化予測

#### 収集データ例
```
- 市場規模: 5,000億円（年成長率5%）
- 主要顧客: 30-40代男性、世帯年収600万円以上
- ニーズ: 品質重視、利便性、環境配慮
- 購買チャネル: オンライン60%、店舗40%
- トレンド: サステナビリティへの関心増加
```

### Competitor（競合）

#### 分析項目
- **競合企業**: 主要競合の特定
- **市場シェア**: 各社のシェア
- **強み・弱み**: 製品、価格、ブランド、チャネル
- **戦略**: どのような戦略を取っているか
- **動向**: 最近の動き、今後の予測

#### 競合比較表
| 項目 | 自社 | 競合A | 競合B |
|------|------|-------|-------|
| シェア | 25% | 30% | 20% |
| 価格帯 | 中～高 | 低～中 | 高 |
| 製品力 | ★★★★☆ | ★★★☆☆ | ★★★★★ |
| ブランド | ★★★☆☆ | ★★★★☆ | ★★★★★ |
| チャネル | 店舗中心 | オンライン | 両方強い |

### Company（自社）

#### 分析項目
- **経営資源**: ヒト、モノ、カネ、情報
- **コア・コンピタンス**: 自社の独自能力
- **強み・弱み**: 競合と比較した強み・弱み
- **現在の戦略**: 取り組んでいる戦略
- **課題**: 解決すべき課題

#### 自社評価
```
【強み】
- 技術力（特許3件保有）
- 顧客サービス（満足度85%）
- 既存顧客基盤（10万社）

【弱み】
- オンライン販売が弱い（シェア10%）
- ブランド認知度が低い（認知率30%）
- 価格競争力に欠ける（競合比+15%）
```

### 3C統合分析

3つを統合し、機会と戦略を導出：

```
【機会（Opportunity）】
- 顧客: サステナビリティ志向増加
- 競合: オンライン対応が遅れている
- 自社: 環境配慮製品の技術あり

【戦略（Strategy）】
環境配慮製品をオンラインで展開し、
サステナビリティ志向顧客を獲得
```

## 3. 5C分析

3C + 協力者 + 競争環境の5つの視点で包括的に分析。

### 5Cの構成

1. **Customer（顧客）** ← 3Cと同じ
2. **Competitor（競合）** ← 3Cと同じ
3. **Company（自社）** ← 3Cと同じ
4. **Collaborator（協力者）**
5. **Context（競争環境）**

### Collaborator（協力者）

#### 分析項目
- **サプライヤー**: 原材料・部品供給者
- **流通業者**: 販売チャネルパートナー
- **協業企業**: 共同開発・共同販売先
- **外部パートナー**: コンサル、広告代理店など

#### 分析観点
```
- 依存度: どれくらい依存しているか
- 交渉力: 価格交渉力はどちらが強いか
- 代替可能性: 他に代替可能か
- 関係性: 良好か、改善余地はあるか
```

### Context（競争環境）

#### PEST分析で構造化

**Political（政治）**:
- 規制・法律の変化
- 政策の方向性
- 補助金・税制

**Economic（経済）**:
- 経済成長率
- 為替レート
- 金利動向

**Social（社会）**:
- 人口動態
- ライフスタイル変化
- 価値観の変化

**Technological（技術）**:
- 新技術の登場
- デジタル化
- イノベーション

#### 例: 電気自動車市場
```
【Political】
- 政府がEV補助金を拡大
- 2035年までにガソリン車販売禁止

【Economic】
- バッテリー価格が年10%低下
- 充電インフラ投資が増加

【Social】
- 環境意識の高まり
- 若年層のEV志向増加

【Technological】
- 全固体電池の開発進展
- 自動運転技術の向上
```

## 4. 4P分析

マーケティングミックスの4要素で製品戦略を分析。

### 4Pの構成

1. **Product（製品）**
2. **Price（価格）**
3. **Place（流通）**
4. **Promotion（販促）**

### Product（製品）

#### 分析項目
- 製品ラインナップ
- 品質・機能
- デザイン
- ブランド
- パッケージ
- アフターサービス

#### 分析テンプレート
```
【製品概要】
- 名称:
- カテゴリー:
- 主要機能:
- 差別化ポイント:

【製品ライフサイクル】
導入期 / 成長期 / 成熟期 / 衰退期

【製品ポートフォリオ】
- 主力製品:
- 成長製品:
- 収益製品:
```

### Price（価格）

#### 価格戦略
- **プレミアム価格**: 高品質・高価格
- **市場浸透価格**: 低価格でシェア獲得
- **競争価格**: 競合と同水準
- **ダイナミックプライシング**: 需要に応じて変動

#### 価格設定方法
```
1. コストベース
   価格 = コスト × (1 + マージン率)

2. 競合ベース
   価格 = 競合価格 ± 差別化分

3. 価値ベース
   価格 = 顧客が感じる価値
```

### Place（流通）

#### チャネル戦略
- **直販**: 自社EC、直営店
- **間接販売**: 小売店、代理店
- **オムニチャネル**: オンライン・オフライン統合

#### 流通カバレッジ
- **開放的流通**: できるだけ多くの店舗で販売
- **選択的流通**: 限定した店舗で販売
- **専属的流通**: 特定の店舗のみで販売

### Promotion（販促）

#### プロモーション手法
- **広告**: TV、Web、新聞、雑誌
- **PR**: プレスリリース、メディア露出
- **セールスプロモーション**: 値引き、クーポン
- **人的販売**: 営業活動
- **SNSマーケティング**: Instagram、Twitter、YouTube

#### IMC（統合マーケティング）
```
全てのプロモーションを統合し、一貫したメッセージを発信

例:
- TV CM: ブランドイメージ訴求
- Web広告: 具体的な製品特徴訴求
- SNS: 顧客との双方向コミュニケーション
- 店頭POP: 購入促進
```

### 4P統合分析

```
【例: 高級腕時計ブランド】

Product: 
- 職人技による高品質
- 限定モデル展開
- 生涯アフターサービス

Price:
- プレミアム価格（30万円～）
- 限定モデルは希少性でプレミアム

Place:
- 専属的流通（高級百貨店のみ）
- 自社直営店（銀座、表参道）

Promotion:
- 雑誌広告（ビジネス誌、ライフスタイル誌）
- ブランドアンバサダー起用
- VIP顧客向けイベント
```

## 5. BCGマトリクス

事業ポートフォリオを市場成長率と相対的市場シェアで分類。

### BCGマトリクスの構成

```
      市場成長率（高）
           ↑
    ┌──────┬──────┐
    │ 問題児 │  花形  │
    │   ?   │   ★   │
    ├──────┼──────┤
    │ 負け犬 │ 金のなる木│
    │   ×   │   $   │
    └──────┴──────┘
          → 相対的市場シェア（高）
```

### 4つの象限

#### 花形（Stars）
**特徴**:
- 高成長市場、高シェア
- 投資が必要だが、収益も大きい

**戦略**:
- 積極投資でシェア維持・拡大
- 市場成長鈍化に備える

**例**: スマートフォン市場のApple（2010年代前半）

#### 金のなる木（Cash Cows）
**特徴**:
- 低成長市場、高シェア
- 安定した収益源

**戦略**:
- 投資を抑え、収益を刈り取る
- 得た利益を他事業に投資

**例**: PC市場のMicrosoft Windows

#### 問題児（Question Marks）
**特徴**:
- 高成長市場、低シェア
- 投資が必要、収益は少ない

**戦略**:
- シェア拡大に投資するか、撤退するか判断
- 「花形」に育てるか、撤退か

**例**: 新興市場への新規参入事業

#### 負け犬（Dogs）
**特徴**:
- 低成長市場、低シェア
- 収益も将来性も低い

**戦略**:
- 撤退または縮小
- 資源を他事業に振り向ける

**例**: 縮小市場での弱小事業

### 適用手順

1. **事業の分類**
   - 各事業の市場成長率を算出
   - 各事業の相対的市場シェアを算出

2. **マトリクスにプロット**
   - 円の大きさ = 事業規模（売上）

3. **ポートフォリオ評価**
   - バランスは良いか？
   - 花形・金のなる木があるか？
   - 問題児が多すぎないか？

4. **戦略立案**
   - 各事業への資源配分を決定
   - 撤退・新規参入を検討

### 例: 家電メーカー

```
【花形】
- ロボット掃除機（市場成長15%、シェア30%）
→ 積極投資

【金のなる木】
- 冷蔵庫（市場成長2%、シェア35%）
→ 利益確保

【問題児】
- スマート家電（市場成長20%、シェア8%）
→ 投資して育てるか判断

【負け犬】
- ブラウン管TV（市場成長-10%、シェア5%）
→ 撤退
```

## 6. Porter 5 Forces

業界の競争構造を5つの要因で分析。

### 5つの Force

```
      ┌────────────┐
      │新規参入の脅威│
      └──────┬─────┘
             │
    ┌────────┼────────┐
    │        │        │
┌───▼──┐  ┌─▼──┐  ┌──▼───┐
│売り手│←→│業界内│←→│買い手│
│の交渉│  │競争  │  │の交渉│
│力    │  └─┬──┘  │力    │
└──────┘    │      └──────┘
         ┌──▼───┐
         │代替品の│
         │脅威    │
         └────────┘
```

### 1. 業界内競争（Rivalry）

#### 分析項目
- 競合企業の数と規模
- 市場成長率
- 製品差別化の程度
- 固定費の比率
- 撤退障壁

#### 競争が激しい条件
```
- 競合が多数存在
- 市場成長率が低い
- 製品が差別化できていない
- 固定費が高い（価格競争になりやすい）
- 撤退障壁が高い（簡単に撤退できない）
```

### 2. 新規参入の脅威（Threat of New Entrants）

#### 参入障壁の種類
- **規模の経済**: 大量生産でコスト優位
- **製品差別化**: 強いブランド、顧客ロイヤルティ
- **資本要件**: 初期投資が巨額
- **流通チャネル**: チャネル確保が困難
- **政府規制**: 許認可が必要
- **既存企業の反撃**: 価格引き下げなど

#### 評価
```
参入障壁が高い → 既存企業に有利
参入障壁が低い → 新規参入者が増え、競争激化
```

### 3. 代替品の脅威（Threat of Substitutes）

#### 分析項目
- 代替品の存在
- 代替品の価格性能比
- 乗り換えコスト

#### 例
```
- タクシー ← Uber、シェアカー
- 新聞 ← オンラインニュース
- 有線電話 ← 携帯電話
```

### 4. 買い手の交渉力（Bargaining Power of Buyers）

#### 交渉力が強い条件
- 買い手の数が少ない（集中度が高い）
- 買い手の購入量が大きい
- 製品の差別化が小さい
- 乗り換えコストが低い
- 買い手の収益性が低い（価格に敏感）

#### 例
```
【交渉力が強い】
- 自動車部品メーカー vs トヨタ
  → トヨタの購入量が巨大、交渉力強い

【交渉力が弱い】
- Apple vs 一般消費者
  → 消費者は個別では小さく、交渉力弱い
```

### 5. 売り手の交渉力（Bargaining Power of Suppliers）

#### 交渉力が強い条件
- 売り手の数が少ない（集中度が高い）
- 代替品がない
- 売り手の製品が重要な投入物
- 乗り換えコストが高い
- 前方統合の脅威（自ら製造・販売に進出）

#### 例
```
【交渉力が強い】
- 半導体メーカー vs 家電メーカー
  → 半導体は代替困難、交渉力強い

【交渉力が弱い】
- 農家 vs 食品メーカー
  → 農家は多数存在、交渉力弱い
```

### 適用手順

1. **各Forceを評価**（強・中・弱）
2. **業界の魅力度を判断**
   - Forceが弱い → 魅力的
   - Forceが強い → 魅力低い
3. **戦略を立案**
   - Forceを弱める方法を検討
   - 有利なポジショニングを探す

### 例: 航空業界

```
【業界内競争】★★★★★（非常に激しい）
- 多数の航空会社、価格競争激化

【新規参入の脅威】★★☆☆☆（中程度）
- 資本要件は高いが、LCCの参入あり

【代替品の脅威】★★★☆☆（中程度）
- 高速鉄道、オンライン会議

【買い手の交渉力】★★★★☆（強い）
- 価格比較が容易、ロイヤルティ低い

【売り手の交渉力】★★★★☆（強い）
- 航空機メーカーは寡占（Boeing、Airbus）

→ 業界の魅力度: 低い
```

## 7. Value Chain（バリューチェーン）

企業活動を主活動と支援活動に分解し、付加価値の源泉を分析。

### バリューチェーンの構造

```
─────────────────────────────────
     支援活動
─────────────────────────────────
企業インフラ（経営管理、財務、法務など）
人的資源管理（採用、育成、評価など）
技術開発（R&D、製品開発など）
調達（原材料、設備、サービスの購入）
─────────────────────────────────
     主活動
─────────────────────────────────
購買物流 → 製造 → 出荷物流 → 販売・マーケ → サービス
                                    ↓
                                  利益
```

### 主活動（Primary Activities）

#### 1. 購買物流（Inbound Logistics）
- 原材料の受入
- 在庫管理
- 倉庫管理

#### 2. 製造（Operations）
- 生産
- 加工
- 組立
- 品質管理

#### 3. 出荷物流（Outbound Logistics）
- 製品の保管
- 配送
- 受注処理

#### 4. 販売・マーケティング（Marketing & Sales）
- 広告
- 販売促進
- 営業活動
- 価格設定

#### 5. サービス（Service）
- アフターサービス
- 修理
- 部品供給
- カスタマーサポート

### 支援活動（Support Activities）

#### 1. 企業インフラ
- 経営管理
- 財務・経理
- 法務
- 総務

#### 2. 人的資源管理
- 採用
- 育成・研修
- 評価・報酬
- 労務管理

#### 3. 技術開発
- 製品開発
- プロセス改善
- IT開発

#### 4. 調達
- 原材料調達
- 設備購入
- 外部サービス調達

### 分析手順

1. **活動の洗い出し**
   - 主活動・支援活動を具体化

2. **コスト分析**
   - 各活動のコストを把握

3. **付加価値分析**

4. **改善機会の特定**
   - コスト削減、差別化の機会

### 例: トヨタ自動車

```
【支援活動】
```

## 8. McKinsey 7S

組織を7つの要素で分析し、整合性を評価。

### 7Sの構成

```
      ┌──────┐
      │Shared │
      │Values │ ← 中心
      └───┬──┘
    ┌─────┼─────┐
    │     │     │
┌───▼┐  ┌▼──┐  ┌▼───┐
│Strat│  │Stru│  │Syst │
│egy │  │ctur│  │ems  │
└────┘  │e   │  └─────┘
        └┬──┘
    ┌────┼────┐
    │    │    │
┌───▼┐ ┌▼──┐ ┌▼───┐
│Staff│ │Skil│ │Style│
└────┘ │ls  │ └────┘
        └────┘
```

### Hard S（変更しやすい）

#### 1. Strategy（戦略）
- 企業の方向性
- 競争戦略
- 成長計画

#### 2. Structure（組織構造）
- 組織図
- 権限と責任
- レポートライン

#### 3. Systems（システム・制度）
- 業務プロセス
- 評価制度
- IT システム

### Soft S（変更しにくい）

#### 4. Shared Values（共有価値観）
- 企業理念
- ミッション・ビジョン
- 企業文化の核

#### 5. Style（スタイル・社風）
- リーダーシップスタイル
- 意思決定の方法
- 社内の雰囲気

#### 6. Staff（人材）
- 従業員のスキル
- 人数・構成
- モチベーション

#### 7. Skills（スキル・能力）
- 組織としての能力
- コアコンピタンス
- 独自技術

### 分析手順

1. **各Sの現状を把握**
2. **整合性をチェック**
   - 7つのSは整合しているか
   - 矛盾はないか
3. **ギャップを特定**
   - あるべき姿と現状のギャップ
4. **改善策を立案**

### 整合性チェックの観点

```
Strategy ↔ Structure
- 戦略に組織構造が合っているか
  例: グローバル戦略なのに国内組織のまま

Strategy ↔ Systems
- 戦略に制度が合っているか
  例: イノベーション重視なのに減点主義の評価制度

Shared Values ↔ Style
- 価値観と実際の行動が一致しているか
  例: 「顧客第一」を掲げるが、社内都合を優先
```

### 例: 企業変革のケース

**状況**: 従来型製造業がDX推進を掲げる

```
【現状の7S】

Strategy: DX推進、データドリブン経営
Structure: 事業部制、縦割り組織
Systems: 紙ベースの業務、手作業が多い
Shared Values: 品質第一、安定志向
Style: トップダウン、慎重な意思決定
Staff: 平均年齢50歳、IT人材不足
Skills: 製造技術は強いが、デジタルスキル弱い

【問題点】
Strategy（DX推進）と他のSが整合していない
- Structure: 縦割りでデータ活用困難
- Systems: デジタル化されていない
- Staff: IT人材不足
- Skills: デジタルスキル弱い

【改善策】
1. Structure: 横断的なDX推進室を設置
2. Systems: 基幹システムのクラウド化
3. Staff: IT人材の採用・育成
4. Skills: 全社デジタル研修の実施
5. Style: アジャイルな意思決定プロセス導入
```

## 9. 損益計算書分析

財務諸表から収益性を分析。

### 損益計算書の構造

```
売上高
  - 売上原価
────────────
売上総利益（粗利）
  - 販売費及び一般管理費
────────────
営業利益
  + 営業外収益
  - 営業外費用
────────────
経常利益
  + 特別利益
  - 特別損失
────────────
税引前当期純利益
  - 法人税等
────────────
当期純利益
```

### 主要な利益指標

#### 1. 売上総利益（粗利）
```
売上総利益 = 売上高 - 売上原価
粗利率 = 売上総利益 / 売上高

【意味】
製品・サービスの付加価値の高さを示す
```

#### 2. 営業利益
```
営業利益 = 売上総利益 - 販売費及び一般管理費
営業利益率 = 営業利益 / 売上高

【意味】
本業での稼ぐ力を示す
```

#### 3. 経常利益
```
経常利益 = 営業利益 + 営業外損益
経常利益率 = 経常利益 / 売上高

【意味】
通常の事業活動での収益力を示す
```

#### 4. 当期純利益
```
当期純利益 = 経常利益 + 特別損益 - 税金
当期純利益率 = 当期純利益 / 売上高

【意味】
最終的な利益、株主への還元原資
```

### 分析の観点

#### 収益性分析
```
【粗利率】
- 高い: 付加価値が高い、価格決定力がある
- 低い: コスト競争、差別化不足

【営業利益率】
- 業界平均と比較
- 時系列での変化

【各利益率のトレンド】
- 改善: 事業が好調
- 悪化: 問題あり
```

#### コスト構造分析
```
売上原価率 = 売上原価 / 売上高
販管費率 = 販管費 / 売上高

【評価】
- 売上原価率が高い: 製造効率が悪い
- 販管費率が高い: 間接費が膨らんでいる
```

### 損益分解ツリー

```
営業利益
├─ 売上総利益
│  ├─ 売上高
│  │  ├─ 販売量
│  │  └─ 単価
│  └─ 売上原価
│     ├─ 変動費
│     └─ 固定費（製造）
└─ 販管費
   ├─ 人件費
   ├─ 広告宣伝費
   ├─ 研究開発費
   └─ その他
```

### 分析例

**企業A（小売業）の損益計算書**:
```
売上高: 1,000億円
売上原価: 700億円（70%）
────────────
売上総利益: 300億円（30%）
販管費: 250億円（25%）
────────────
営業利益: 50億円（5%）
```

**分析**:
```
- 粗利率30%: 小売業としては標準的
- 営業利益率5%: 業界平均3-5%と同水準
- 販管費率25%: やや高い、削減余地あり
```

**改善提案**:
```
1. 仕入原価の削減（粗利率向上）
   - サプライヤーとの交渉
   - PB商品の拡大

2. 販管費の削減（営業利益率向上）
   - 人件費の適正化
   - 店舗オペレーションの効率化
```

## 10. 内部・外部要因分解

問題を内部要因と外部要因に分けて分析。

### 内部要因 vs 外部要因

```
┌────────────┬────────────┐
│  外部要因    │  内部要因    │
│(コントロール不可)│(コントロール可)│
├────────────┼────────────┤
│ 市場環境     │ 製品・サービス│
│ 競合動向     │ 価格設定     │
│ 法規制       │ 販売チャネル │
│ 経済状況     │ マーケティング│
│ 技術トレンド │ オペレーション│
│ 顧客トレンド │ 組織・人材   │
└────────────┴────────────┘
```

### 分析手順

1. **問題を列挙**
2. **内部・外部に分類**
3. **優先順位をつける**
4. **対策を立案**
   - 内部要因: 改善策を実行
   - 外部要因: 適応策を検討

### 例: 売上減少の分析

```
【売上減少の要因分解】

外部要因:
1. 市場全体の縮小（-2%）
2. 競合Aの低価格攻勢
3. 消費者の節約志向

内部要因:
1. 商品ラインナップの陳腐化
2. 販売員のスキル不足
3. マーケティング予算削減
4. 品質問題の発生

【対策】

外部要因への対応:
- 市場縮小: 新市場開拓、海外展開
- 競合の低価格: 差別化強化、価値訴求
- 節約志向: お得感のある商品投入

内部要因の改善:
- 商品陳腐化: 新商品開発
- スキル不足: 販売研修の実施
- 予算削減: マーケ予算の見直し
- 品質問題: 品質管理体制の強化
```

## 11. IFシナリオ分析

複数の「もし〇〇だったら」シナリオで将来を予測。

### シナリオ分析の手順

#### Step 1: 不確実性の特定
```
将来に影響する不確実な要素を列挙

例:
- 経済成長率
- 技術革新のスピード
- 規制の変化
- 競合の動き
```

#### Step 2: シナリオの設定
```
楽観シナリオ / 基本シナリオ / 悲観シナリオ

または

2軸でのシナリオマトリクス
```

#### Step 3: 各シナリオの詳細化
```
- 前提条件
- 市場環境
- 事業への影響
- 必要な対応
```

#### Step 4: 戦略の策定
```
- 各シナリオでの戦略
- 共通して有効な戦略
- 早期警戒指標
```

### 2軸シナリオマトリクス

```
例: 電気自動車市場

           技術進化（速い）
                ↑
        ┌───────┬───────┐
        │シナリオA│シナリオB│
規制緩い←┤大衆化加速│テック主導├→規制厳しい
        │シナリオC│シナリオD│
        │現状維持 │規制主導 │
        └───────┴───────┘
                ↓
           技術進化（遅い）
```

### シナリオの例

**シナリオA: 大衆化加速**
```
【前提】
- バッテリー技術が急速に進歩
- 規制は緩やか、市場競争が促進

【市場環境】
- EV価格がガソリン車並みに
- 多数のメーカーが参入
- 充電インフラが急速に整備

【事業への影響】
- 市場は急拡大
- 価格競争が激化
- 差別化が困難に

【戦略】
- 低コスト化を推進
- 生産規模拡大
- 独自技術で差別化
```

**シナリオD: 規制主導**
```
【前提】
- バッテリー技術の進歩は緩やか
- 政府が厳しい環境規制を導入

【市場環境】
- EV義務化、ガソリン車販売禁止
- しかし技術は未成熟、価格は高止まり
- 補助金に依存した市場

【事業への影響】
- 規制対応が必須
- 収益性は低い
- 政策リスクが高い

【戦略】
- 最低限の規制対応
- ハイブリッドで時間を稼ぐ
- 技術開発に投資継続
```

### シナリオ分析の活用

**早期警戒指標の設定**:
```
- バッテリーコストが $100/kWh を下回ったら → シナリオAの可能性
- EU が 2030年までにガソリン車禁止を決定 → シナリオDの可能性
```

**柔軟な戦略**:
```
どのシナリオでも有効な施策:
- 電池技術への継続投資
- 充電インフラとの提携
- 顧客データの蓄積

シナリオ依存の施策:
- シナリオA: 大規模生産投資
- シナリオD: 政策対応チームの強化
```

## 12. SWOT分析

内部の強み・弱みと、外部の機会・脅威を分析。

### SWOTの構成

```
         内部環境
    ┌──────┬──────┐
    │Strengths│Weakness │
    │(強み)    │(弱み)    │
外  ├──────┼──────┤
部  │Opportuni│Threats   │
環  │ties      │(脅威)    │
境  │(機会)    │          │
    └──────┴──────┘
```

### クロスSWOT分析

各象限の組み合わせで戦略を導出:

```
        強み(S)      弱み(W)
      ┌──────┬──────┐
機会  │ SO戦略  │ WO戦略  │
(O)   │積極的攻勢│弱み克服 │
      ├──────┼──────┤
脅威  │ ST戦略  │ WT戦略  │
(T)   │差別化   │撤退・縮小│
      └──────┴──────┘
```

**SO戦略（強み × 機会）**:
- 強みを活かして機会を掴む
- 最も積極的な戦略

**WO戦略（弱み × 機会）**:
- 弱みを克服して機会を掴む
- 改善投資が必要

**ST戦略（強み × 脅威）**:
- 強みで脅威に対抗
- 差別化戦略

**WT戦略（弱み × 脅威）**:
- 最も不利な状況
- 撤退・縮小も検討

### 例: カフェチェーン

```
【Strengths(強み)】
- 立地の良い店舗網
- ブランド認知度が高い
- 質の高い接客

【Weaknesses(弱み)】
- 価格が高め
- デジタル対応が遅れている
- メニューの種類が少ない

【Opportunities(機会)】
- 在宅勤務増加でカフェ利用増
- サステナビリティへの関心増
- デジタル決済の普及

【Threats(脅威)】
- 競合の低価格攻勢
- コンビニコーヒーの台頭
- 原材料価格の上昇

【クロスSWOT戦略】

SO戦略:
- 立地を活かし、リモートワーク客を取り込む
- サステナブルな商品でブランド価値向上

WO戦略:
- モバイルオーダー導入（デジタル対応）
- デリバリー参入（新チャネル）

ST戦略:
- 質の高い接客で差別化
- プレミアム路線でコンビニと差別化

WT戦略:
- 低価格メニューの追加
- 原価管理の徹底
```

## 13. STP分析

市場細分化、ターゲット選定、ポジショニングの3ステップ。

### Segmentation（市場細分化）

市場を同質なグループに分割。

#### 細分化の軸

**消費財市場**:
- **地理的**: 国、地域、都市規模
- **人口統計的**: 年齢、性別、所得、職業、学歴
- **心理的**: ライフスタイル、価値観、性格
- **行動的**: 購買頻度、使用量、ブランドロイヤルティ

**B2B市場**:
- **地理的**: 国、地域
- **企業規模**: 従業員数、売上高
- **業種**: 製造業、サービス業など
- **購買行動**: 購買基準、意思決定プロセス

### Targeting（ターゲット選定）

どのセグメントを狙うかを決定。

#### 評価基準
1. **市場規模**: 十分な規模があるか
2. **成長性**: 成長が見込めるか
3. **収益性**: 利益が確保できるか
4. **競合状況**: 競争が激しくないか
5. **自社適合性**: 自社の強みが活かせるか
6. **到達可能性**: マーケティング活動が届くか

#### ターゲティング戦略

**無差別型**:
- 全市場を対象
- マスマーケティング

**差別型**:
- 複数セグメントを対象
- セグメント別に施策

**集中型**:
- 1つのセグメントに集中
- ニッチ戦略

### Positioning（ポジショニング）

ターゲット顧客の心の中での位置づけを決定。

#### ポジショニングマップ

```
2軸でのマップ作成

例: 自動車市場

           高価格
              ↑
       ┌──────┼──────┐
       │高級車 │  │ ？ │
実用的 ←┼──────┼──────┤→ スポーティ
       │大衆車 │  │スポーツ│
       └──────┼──────┘
              ↓
           低価格
```

#### ポジショニングステートメント

```
[ターゲット]のための[カテゴリー]は、
[競合とは異なり]、[独自の価値]を提供します。

例:
「健康志向の20-30代女性のためのヨーグルトは、
従来の甘いヨーグルトとは異なり、
砂糖ゼロで罪悪感なく楽しめる味を提供します」
```

### STP分析の例

**市場**: スポーツシューズ

**Segmentation**:
```
1. プロアスリート
2. 週末ランナー
3. ファッション志向
4. 高齢者の健康維持
```

**Targeting**:
```
【選定セグメント】週末ランナー

【理由】
- 市場規模: 500万人
- 成長性: 年5%成長
- 収益性: 中価格帯で利益確保可能
- 競合: 大手は少ない
- 自社適合性: 技術力を活かせる
```

**Positioning**:
```
【ポジショニング】
「週末ランナーのための、
プロ仕様の技術を手頃な価格で提供する
本格ランニングシューズ」
```
