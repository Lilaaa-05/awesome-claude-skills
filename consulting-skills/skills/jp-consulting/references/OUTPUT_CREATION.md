## 1. ストーリーライン構築

### ピラミッドストラクチャー

```
        [結論・提言]
             ↓
    [根拠1] [根拠2] [根拠3]
       ↓       ↓       ↓
    [データ] [データ] [データ]
```

**原則**:
- トップに結論
- その下に根拠
- 最下層にデータ・事実

### ストーリーラインの作り方

#### Step 1: メインメッセージの決定

```
【良い例】
「X市場への参入を推奨する」
「価格を10%下げることで売上20%増が見込める」

【悪い例】
「X市場について分析した」← 何が言いたいか不明
```

#### Step 2: 根拠の整理（MECE）

```
メインメッセージ: X市場への参入を推奨

根拠1: 市場が魅力的
根拠2: 参入障壁が低い
根拠3: 自社の強みが活かせる

→ MECEに整理されている
```

#### Step 3: スライドの構成

```
スライド1: 表紙
スライド2-3: エグゼクティブサマリー
スライド4-6: 現状分析
スライド7-15: 詳細分析
スライド16-18: 提言・Next Steps
```

## 2. スライドの作り方

### 1スライド1メッセージの原則

**各スライドに明確なメッセージを**:

```
◯ 良い例:
タイトル: 「市場は年10%で成長しており魅力的」
コンテンツ: 市場規模と成長率のグラフ

× 悪い例:
タイトル: 「市場分析」
コンテンツ: 様々なデータが羅列
→ 何が言いたいのか不明
```

### スライドの基本構造

```markdown
# スライド番号: メッセージを含むタイトル

## メインメッセージ
[このスライドで伝えたい核心を1文で]

## コンテンツ
[図表、箇条書き、データなど]

## 示唆（So What）
[このデータから何が言えるか]
```

### スライドタイトルの書き方

**メッセージ型タイトル（推奨）**:
```
◯ 「市場は年10%で成長しており魅力的」
◯ 「競合Aは価格で優位だが、品質では劣る」
◯ 「参入方法はM&Aが最適」

× 「市場分析」← 何が言いたいか不明
× 「競合比較」← 何が言いたいか不明
```

## 3. エグゼクティブサマリー

### 構成（1-2ページ）

```
1. 背景・課題
   - なぜこの分析を行ったのか

2. 分析の概要
   - 何を分析したのか

3. 主要な発見事項（Key Findings）
   - 最も重要な3-5個の発見

4. 提言（Recommendations）
   - 何をすべきか
   - 優先順位

5. 期待効果
   - 実施した場合の効果
```

### 例

```markdown
# エグゼクティブサマリー

## 背景
売上減少に対応するため、X市場への参入可否を検討

## 分析概要
- 市場魅力度分析
- 参入障壁評価
- 自社適合性評価

## 主要発見事項
1. X市場は年10%成長、5年後に1兆円市場
2. 参入障壁は中程度（資本50億円、技術は保有）
3. 自社の技術力が差別化要因になる

## 提言
X市場への参入を推奨。M&Aで迅速に参入すべき

## 期待効果
3年後に売上500億円、営業利益率15%を達成
```

## 4. 現状分析セクション

### 目的
「今、どうなっているのか」を示す

### 構成例

```
スライド1: 業界概況
スライド2: 市場規模・成長率
スライド3: 競合状況
スライド4: 自社の現状
スライド5: 課題の整理
```

### 図表の活用

#### 市場規模・成長率
```
【グラフの種類】
- 棒グラフ: 年度別市場規模
- 折れ線グラフ: 成長率推移

【示唆を明記】
「市場は過去5年間、年平均10%で成長」
```

#### 競合比較
```
【表形式】
| 項目 | 自社 | 競合A | 競合B |
|------|------|-------|-------|
| シェア | 25% | 30% | 20% |
| 価格 | 中 | 低 | 高 |
| 品質 | 高 | 中 | 高 |

【示唆を明記】
「競合Aは価格優位、競合Bは品質優位。
 自社は中間ポジションで差別化が不足」
```

#### イシューツリー
```
【樹形図で構造化】
売上減少
├─ 顧客数減少
│  ├─ 新規獲得減
│  └─ 既存離反増
└─ 客単価低下
   ├─ 値下げ
   └─ 商品構成変化
```

## 5. 詳細分析セクション

### 目的
「なぜそうなっているのか」「どうすべきか」を示す

### 構成例

```
分析観点1（5-7スライド）:
- 分析結果
- データ・根拠
- 示唆

分析観点2（5-7スライド）:
- 分析結果
- データ・根拠
- 示唆

分析観点3（3-5スライド）:
- 分析結果
- データ・根拠
- 示唆
```

### データの見せ方

#### 定量データ
```
【原則】
- 数値は丸める（3,456,789円 → 約350万円）
- 重要な数値を強調
- 出所を明記

【例】
市場規模: 5,000億円（出所: ○○調査）
成長率: 年10%（出所: △△統計）
```

#### 定性データ
```
【顧客の声】
「〇〇が不便だと感じている」（顧客アンケート、n=500）

【専門家の見解】
「今後3年で市場が大きく変化する」（○○氏、業界専門家）
```

### フレームワークの使用

```
【明示する】
「Porter 5 Forcesで業界構造を分析した結果...」

【図示する】
フレームワークの図を入れ、各要素の評価を記載
```

## 6. 提言・Next Stepsセクション

### 構成

```
スライド1: 提言のサマリー
スライド2: 提言の詳細
スライド3: 実行計画（ロードマップ）
スライド4: 期待効果
スライド5: リスクと対応策
```

### 提言の書き方

**具体的でアクショナブルに**:

```
◯ 良い例:
「X社をY億円で買収し、Z市場に参入すべき」
「価格を10%下げ、広告費を20%増やすべき」

× 悪い例:
「市場参入を検討すべき」← 何をどうするのか不明
「マーケティングを強化すべき」← 具体性がない
```

### 実行計画（ロードマップ）

```
【ガントチャート形式】

           Q1   Q2   Q3   Q4
Phase 1:  ████
デューデリ

Phase 2:       ████████
買収実行

Phase 3:            ████████
PMI

Phase 4:                 ████
事業開始
```

### 期待効果

```
【定量化する】
- 売上: +500億円（3年後）
- 営業利益率: 15%
- 市場シェア: 10%

【前提条件を明記】
前提: 市場が予測通り成長、統合が順調に進む
```

### リスクと対応策

```
| リスク | 発生確率 | 影響度 | 対応策 |
|--------|----------|--------|--------|
| 市場成長鈍化 | 中 | 大 | 他市場も検討 |
| PMI失敗 | 中 | 大 | 専門家起用 |
| 競合の反撃 | 高 | 中 | 差別化強化 |
```

## 7. 図表の作り方

### グラフの選び方

```
【棒グラフ】
用途: 数値の比較
例: 各年度の売上、各社のシェア

【折れ線グラフ】
用途: 時系列の推移
例: 売上の推移、市場成長率の推移

【円グラフ】
用途: 構成比
例: 市場シェア、売上の内訳

【散布図】
用途: 相関関係
例: 価格と販売量の関係

【ウォーターフォール】
用途: 増減の内訳
例: 売上の増減要因
```

### 表の作り方

```
【原則】
- シンプルに
- 重要な数値を強調（太字、色）
- 縦線は最小限
- 単位を明記

【例】
売上推移（億円）

年度  | 売上 | 成長率
------|------|-------
2022  | 100  | -
2023  | 110  | +10%
2024  | 125  | +14%
```

### 図の作り方

```
【フローチャート】
業務プロセスの可視化

【組織図】
組織構造の表現

【ベン図】
要素の関係性

【マトリクス】
2軸での整理（BCG、SWOT など）
```

## 8. 品質チェックリスト

### 論理性チェック

- [ ] メインメッセージは明確か
- [ ] 各スライドにメッセージがあるか
- [ ] メッセージとデータが一致しているか
- [ ] 論理の飛躍はないか
- [ ] ストーリーに一貫性があるか

### コンサル品質チェック

- [ ] So What（示唆）が明確か
- [ ] MECEに整理されているか
- [ ] 結論がアクショナブルか
- [ ] データの出所が明記されているか
- [ ] 前提条件が明示されているか

### 視覚的品質チェック

- [ ] 1スライド1メッセージか
- [ ] タイトルがメッセージ型か
- [ ] 図表は適切か
- [ ] フォントサイズは適切か（最小14pt）
- [ ] 色使いは適切か（多色使いすぎない）

### 実行可能性チェック

- [ ] 提言は具体的か
- [ ] 実行計画は現実的か
- [ ] 期待効果は妥当か
- [ ] リスクと対応策が示されているか

## 9. Markdown形式での記述

### 基本フォーマット

```markdown
# スライド1: タイトル（メインメッセージ）

## メインメッセージ
[核心的メッセージを1文で]

## 背景・状況
[なぜこのスライドが必要か]

## コンテンツ

### グラフ・図表の説明
[図表の内容を文章で説明]

### データ
- データポイント1
- データポイント2
- データポイント3

## 示唆・So What
[このデータから何が言えるか]
[次に何をすべきか]

---
```

### 例

```markdown
# スライド7: 市場は年10%で成長しており魅力的

## メインメッセージ
X市場は過去5年間、年平均10%で成長しており、
今後も同様の成長が見込まれる

## コンテンツ

### 市場規模の推移

| 年度 | 市場規模（億円） | 成長率 |
|------|-----------------|--------|
| 2019 | 3,000           | -      |
| 2020 | 3,300           | +10%   |
| 2021 | 3,600           | +9%    |
| 2022 | 4,000           | +11%   |
| 2023 | 4,400           | +10%   |
| 2024予測 | 4,800       | +9%    |

出所: ○○調査（2024年3月）

### 成長要因
- 消費者の健康志向増加
- 新規参入による市場活性化
- デジタル化による購買利便性向上

## 示唆・So What
市場の成長性は高く、参入のタイミングとして好機。
今後3年以内に参入すべき。

---
```

## 10. PowerPointへの変換（オプション）

### 変換スクリプトの使用

```bash
python scripts/generate_pptx.py input.md output.pptx --template standard
```

### テンプレートの選択

**standard（標準）**:
- 汎用的なデザイン
- ビジネス全般に使用可能

**executive（エグゼクティブ向け）**:
- シンプルでクリーン
- 経営層向けプレゼン

**detailed（データ詳細版）**:
- データ・図表が多い資料向け
- 詳細分析レポート

### 手動での PowerPoint 作成

Markdownをもとに、PowerPointで以下を調整：

1. **レイアウト**
   - タイトルスライド
   - タイトルとコンテンツ
   - 2カラム

2. **デザイン**
   - フォント: メイリオ、游ゴシック
   - フォントサイズ: タイトル28pt、本文14-18pt
   - 色: 企業カラー、アクセントカラー

3. **図表の作成**
   - Excel でグラフ作成
   - PowerPoint にコピー
   - 見やすく調整

## 11. レビューとフィードバック

### セルフレビュー

完成後、24時間置いてから再度見直す：

- [ ] 誤字脱字はないか
- [ ] 数値は正確か
- [ ] 論理は通っているか
- [ ] メッセージは明確か

### ピアレビュー

可能であれば、第三者にレビューしてもらう：

- 理解できるか
- 説得力があるか
- 改善点はないか

## 12. プレゼンテーションのコツ

### 準備

- [ ] ストーリーを頭に入れる
- [ ] 想定質問への回答を準備
- [ ] タイムマネジメント（1スライド1-2分）

### 話し方

- **結論から話す**
- **数値は丸めて話す**（3,456,789円 → 約350万円）
- **専門用語を避ける**（必要なら説明）
- **自信を持って話す**

### 質疑応答

- **質問を理解する**（不明な場合は確認）
- **簡潔に答える**
- **分からない場合は正直に**（「後ほど確認します」）

## 13. 資料作成のベストプラクティス

### Do（すべきこと）

✓ 結論を先に
✓ データに基づく
✓ MECEに整理
✓ So Whatを明示
✓ シンプルに
✓ 読み手視点で

### Don't（すべきでないこと）

× 結論を最後に
× 感覚・印象で語る
× 羅列だけ
× データだけで示唆なし
× 複雑にしすぎる
× 自己満足の資料

## 14. 各種フォーマット対応

### コンサルティング会社別フォーマット

**McKinsey風**:
- シンプル、ミニマル
- データ中心
- 論理性重視

**BCG風**:
- ビジュアル重視
- インフォグラフィック多用
- 色使いが豊富

**Bain風**:
- 実行重視
- アクションプラン明確
- ROI・効果を強調

ユーザーから特定のフォーマット指定があれば、それに応じて調整。

## 15. Tips集

### スライド作成の時短テク

1. **テンプレートを用意**
   - よく使うスライドレイアウト
   - よく使う図表

2. **再利用する**
   - 過去の資料から流用
   - 業界標準の図表を活用

3. **アウトラインから作る**
   - 最初に全体構成
   - 各スライドのメッセージを先に決める
   - 最後にデータ・図表を作成

### データ収集の効率化

1. **信頼できるソースをブックマーク**
   - 政府統計（e-Stat）
   - 業界団体サイト
   - 調査会社レポート

2. **検索キーワードを工夫**
   - 「[業界名] 市場規模」
   - 「[企業名] IR資料」
   - 「[テーマ] 白書」

3. **フェルミ推定を活用**
   - データがない場合は概算
   - 前提条件を明示

### 説得力を高めるコツ

1. **ストーリーで語る**
   - データの羅列ではなく、ストーリーとして構成

2. **ビジュアルを効果的に使う**
   - 複雑なデータは図表で
   - 重要な数字は大きく

3. **具体例を入れる**
   - 抽象的な話には具体例
   - 成功事例を引用

4. **反論に備える**
   - 想定される反論を先に潰す
   - リスクと対応策を示す
